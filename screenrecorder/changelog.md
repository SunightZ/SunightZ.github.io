# 更新日志

当前提供 **精简版 3.0**。完整版由开发者通过社群渠道单独发布，版本节奏与精简版不完全一致。

## 精简版 3.0

- **只保留系统录屏链路**：移除 Shizuku / Root 采集与触摸可视化，包体与权限范围更收敛；其余功能原样保留。
- **权限只在第一次询问**：明确拒绝过的权限不再重复弹窗，改为按说明降级继续（拒绝相机不显示小窗、拒绝录音无声录制、拒绝通知照常录制），并合并成一条提示；想恢复就到系统设置里打开，应用会自动重新走询问流程。
- **相册权限同样只问一次**：拒绝后页面直接给出「去系统设置」入口，不再反复弹出说明与系统弹窗。
- **动态开屏图标**：启动图标的圆环绘制、圆点回弹与两圈光晕扩散由矢量动画实现，深浅色各自配色。
- **视频工具箱**：格式转换、提取音频、压缩、旋转与镜像、音量调整、视频超分、抖音投稿帧数优化。
- **录制链路**：MediaProjection → OpenGL 旋转处理层 → MediaCodec；系统声音走播放捕获，麦克风独立采集，两路混音后编码 AAC。

## 完整版（社群渠道）

在精简版能力之上，额外提供：

- **Shizuku 采集**：免系统录屏弹窗，隐藏 API 直接镜像主屏；系统声音经 shell 进程捕获并保留本机播放。
- **Root 采集**：由系统级进程采集，高帧率下掉帧与 CPU 占用更低。
- **显示触摸位置**：录制中显示点按反馈。

## 关于版本号

精简版与完整版共用包名与大部分代码，版本号按各自的构建单独推进，因此同名版本不代表功能完全相同——以[版本对比](./versions.md)为准。

> 历史改动的完整记录见 GitHub 仓库的提交历史。
