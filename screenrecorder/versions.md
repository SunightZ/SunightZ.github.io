# 版本对比

「小白录制」有两个工程版本：**完整版**（含 Root / Shizuku 录制）与**精简版**（只保留系统录屏）。功能与权限范围不同，选择取决于你要录什么。

## 三种录制方式的差别

**系统录屏（两个版本都有）**
调用系统录屏授权。优点是什么都不用额外准备；代价是每次开始都要确认一次系统弹窗。

**Shizuku（仅完整版）**
装好 Shizuku 后，录制不再需要每次确认系统弹窗，点击即开始；录系统声音时手机照常出声，不会变静音。

**Root（仅完整版）**
由系统级权限录制，画面更稳。开发者在同一台设备上测得的对比（会随设备与负载变化）：

| 指标 | 系统录制 | Shizuku | Root |
| --- | --- | --- | --- |
| 每帧 CPU | 8.89 ms | 6.40 ms | 6.20 ms |
| 超预算帧 | 1.87% | 1.27% | 1.25% |
| 掉帧 | 1.70% | 1.45% | 1.24% |

Root 还有一个实际好处：录制过程不依赖应用本身，**应用被划掉或被杀，录制照样正常结束并保存**。

## 高级版

完整版的 Root / Shizuku 录制、屏幕标注、触摸可视化与外部 Activity 静默启动属于高级版权益：

- Root / Shizuku 与触摸可视化未激活时每次可体验 1 分钟
- 屏幕标注与外部启动未激活时完全不可用
- **系统录屏完全免费，没有时长限制**

详见[高级版权益](./premium/index.md)。

## 我该选哪个

- 只是想把手机屏幕录下来、偶尔剪一下 → **精简版**，装完就能用。
- 常录游戏、要 120 FPS 且不想每次点系统弹窗 → **完整版**（Shizuku 即可，Root 更稳）。
- 需要录制时显示点按操作、或录制中圈点标注 → **完整版**。

## 版本限制（两个版本共同）

- 受保护内容（部分应用的版权视频、支付页等）系统不允许录制，录出来可能是黑屏。
- 可用分辨率、帧率、码率最终由手机硬件决定，页面上的上限不等于设备保证支持。
- 强制结束进程或设备断电不能保证视频完整；保存失败时临时文件会保留。
- Shizuku 依赖系统实现，部分机型需要额外兼容处理，失败时会明确提示，可以改用系统录屏。
- 只支持 64 位（arm64-v8a）设备。
