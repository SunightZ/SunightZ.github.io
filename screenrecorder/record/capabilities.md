# 参数与设备支持

页面上的参数上限**不等于你的手机一定支持**。真正能录到什么分辨率、帧率、码率，由手机的硬件编码能力决定。这一页说明应用会怎么帮你避开不支持的组合。

## 首次启动会自动调整

安装后第一次打开应用时，它会检查你的手机支持哪些组合，把默认参数调到设备能稳定支持的最高一档，然后提示：

> 已按设备编码能力调整录制参数：`{宽}×{高}` · `{帧率}` FPS

这一步**只在第一次安装时执行一次**。之后你自己改过的设置不会被覆盖。

## 参数设太高会怎样

应用会在**开始录制前**就检查，不支持的组合会直接告诉你原因，而不是录出一堆坏帧。提示按最贴近原因的那一条给出：

| 情况 | 提示 |
| --- | --- |
| 设备没有可用的硬件编码器 | 没有找到可用的 H.265/H.264 硬件编码器，可把「编码选择」改为软件编码再试 |
| 设备没有可用的软件编码器 | 没有找到可用的 H.265/H.264 软件编码器 |
| 不支持恒定码率 | 该编码器不支持当前码率下的固定码率（CBR），请把码率模式改回可变码率（VBR） |
| 帧率超过该分辨率的上限 | `{宽}×{高}` 在该编码器下的帧率上限是 `{上限}` FPS，请把帧率降到 `{上限}` 或更低 |
| 其他组合问题 | 编码器不接受 `{宽}×{高}` · `{帧率}` FPS · `{码率}` Mbps 这一整套参数，请降低分辨率、帧率或码率 |

<div class="sr-note">
<strong>四项单独都能过、组合起来不行，是最常见的情况。</strong>例如 1920×1080 可以、60 FPS 也可以，但两者一起就不行。这种时候应用会标红<strong>帧率</strong>那一项——先试着降帧率。
</div>

## 查看设备支持到哪

主页「画面设置」里有「设备编码器能力」入口，点开可以看到：

- 每个可用编码器的名称，以及是硬件还是软件编码
- 支持的宽度、高度范围
- 码率范围
- 当前尺寸下可用的帧率范围
- 当前参数组合是否支持

对话框结尾有一句说明：

> 以上为系统报告的能力；宽、高、帧率上限不能任意组合，实际运行仍受设备负载影响。

## 常见误解

**「我的手机是 120 Hz，所以能录 120 FPS」**
屏幕刷新率只决定帧率的**上限**。能不能真的以 120 FPS 录，取决于手机在你要的分辨率下是否支持——很多设备只在 1080p 及以下开放高帧率。

**「静态画面时帧数不对」**
帧率是目标/上限，静态画面不保证持续生成这么多帧。录一段不动的画面，文件里可能只有很少的帧，这是正常的。

**「模拟器上能跑，真机不行」**
模拟器的编码能力与真机差别很大。判断方式是拿真机试。
