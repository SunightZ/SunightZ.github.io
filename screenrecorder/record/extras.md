# 摄像头小窗与启动音效

两个和录制画面/录制体验相关的小功能，都在主页上。

## 前置摄像头

主页「画面设置」里的「前置摄像头」开关，摘要写着「录制时显示可拖动的前置摄像头悬浮窗口」。

打开后，录制期间屏幕上会出现一个圆形的小窗，显示前置摄像头的实时画面：

| 项目 | 值 |
| --- | --- |
| 窗口尺寸 | 118 dp × 118 dp |
| 形状 | 正圆（用椭圆轮廓裁切） |
| 初始位置 | 屏幕左上角附近 |
| 拖动 | 按住任意位置拖动，**不做边界限制**，可以拖出屏幕 |
| 打开时机 | 录制开始后淡入（等摄像头会话配置好再显示，避免黑屏闪一下） |

<div class="sr-note">
<strong>小窗会被录进画面</strong>——这正是这个功能的用途。它和悬浮球不同，不在「排除录屏」图层上。
</div>

### 需要两个权限

1. **悬浮窗权限**：小窗要显示在录制画面之上。
2. **相机权限**：只找前置摄像头（`LENS_FACING_FRONT`），用 Camera2 的预览模板。

缺少时分别提示：

| 缺什么 | 提示 |
| --- | --- |
| 悬浮窗权限 | 缺少悬浮窗权限，本次录制不显示摄像头小窗 |
| 相机权限 | 前置摄像头预览需要相机权限，已跳过预览 |

两种情况都**不影响录制本身**——屏幕照录，只是没有小窗。这与区域录制不同（区域录制没有悬浮窗权限就无法降级）。

### 能力范围

只提供前置摄像头的实时预览小窗。没有镜像/翻转开关、没有尺寸调整、点击不能关闭、不支持后置摄像头，也不会把摄像头画面合成进视频流之外做额外处理。

## 启动音效

主页「启动音效」区块，一个总开关加六个内置音效的单选（默认「哎呦我去」）：

| 音效 | 说明 |
| --- | --- |
| 哎呦我去 | 默认选项 |
| 冰冰冰 | |
| 叹气 | |
| 哇啊哦 | |
| 哇哦 | |
| 呦吼吼 | |

行为：

- 开关与选择**自动保存**，从控制中心启动同样生效。
- **录制启动成功后**才播放，播放最长 5 秒。
- 停止录制时停止播放。
- 不支持导入自定义音频文件。

<div class="sr-note">
<strong>麦克风可能把提示音一起录进去。</strong>用扬声器播放时，如果同时开着麦克风，提示音会被录入。介意的话用耳机，或者关掉启动音效。
</div>
