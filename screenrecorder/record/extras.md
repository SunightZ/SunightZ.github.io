# 摄像头小窗与启动音效

两个和录制画面、录制体验相关的小功能，都在主页上。

## 前置摄像头

主页「画面设置」里的「前置摄像头」开关，说明写着「录制时显示可拖动的前置摄像头悬浮窗口」。

打开后，录制期间屏幕上会出现一个圆形小窗，显示前置摄像头的实时画面：

| 项目 | 说明 |
| --- | --- |
| 大小 | 约 118 dp 的正圆 |
| 位置 | 默认在左上角附近 |
| 拖动 | 按住拖动到任意位置 |
| 出现时机 | 录制开始后自动出现 |

<div class="sr-note">
<strong>小窗会被录进画面</strong>——这正是这个功能的用途，适合做真人出镜的讲解。
</div>

### 需要两个权限

1. **悬浮窗权限**：小窗要显示在录制画面之上。
2. **相机权限**：读取前置摄像头画面。

缺少时分别提示：

| 缺什么 | 提示 |
| --- | --- |
| 悬浮窗权限 | 缺少悬浮窗权限，本次录制不显示摄像头小窗 |
| 相机权限 | 前置摄像头预览需要相机权限，已跳过预览 |

两种情况都**不影响录制本身**——屏幕照录，只是没有小窗。

### 说明

只提供前置摄像头的实时预览小窗。没有镜像 / 翻转开关，不能调整大小，点击不能关闭，也不支持后置摄像头。

## 启动音效

主页「启动音效」区块，一个总开关加六个内置音效的单选（默认「哎呦我去」）：

| 音效 |
| --- |
| 哎呦我去（默认） |
| 冰冰冰 |
| 叹气 |
| 哇啊哦 |
| 哇哦 |
| 呦吼吼 |

行为：

- 开关与选择**自动保存**，从控制中心启动同样生效。
- **录制启动成功后**才播放，最长 5 秒。
- 停止录制时停止播放。
- 不支持导入自定义音频。

<div class="sr-note">
<strong>麦克风可能把提示音一起录进去。</strong>用扬声器播放时，如果同时开着麦克风，提示音会被录入。介意的话用耳机，或者关掉启动音效。
</div>
