# 屏幕标注

录制过程中直接在屏幕上圈点、划线、写字，标注会实时出现在录制结果里。适合边讲边指。

<div class="sr-note">
<strong>高级版功能。</strong>未激活时打开标注会提示「屏幕标注需要激活高级版」。详见<a href="/premium/">高级版权益</a>。
</div>

## 打开方式

三个入口，都要**先开始录制**：

1. 悬浮球菜单里的「标注」
2. 悬浮菜单页里的「屏幕标注」按钮
3. 录制通知栏的「标注」动作

没在录制时打开会提示「开始录制后才可使用屏幕标注」。

## 工具条

工具条是一个深色（浅色主题下为浅色）圆角面板，宽 220dp，从上到下四行：

### 表头行

| 控件 | 说明 |
| --- | --- |
| `⠿` 拖动柄 | 拖动改变工具条位置，位置会被记住 |
| `操作 ⇄` / `绘制 ⇄` | 切换「绘制」与「操作」两种模式 |
| `×` | 退出标注 |

### 颜色行

六个色块，点选即换色：

| 颜色 | 色值 |
| --- | --- |
| 红色（默认） | `#FF453A` |
| 黄色 | `#FFC107` |
| 绿色 | `#34C759` |
| 蓝色 | `#409CFF` |
| 白色 | 纯白 |
| 黑色 | 纯黑 |

### 形状行

四个工具，点选即换：

| 工具 | 说明 |
| --- | --- |
| 自由线（默认） | 随手画，快速圈重点或写字 |
| 矩形 | 突出显示界面、按钮和关键区域 |
| 圆形 | 强调目标位置或操作结果 |
| 箭头 | 指向具体控件、方向或变化位置 |

已画好的笔画不会因为切换工具而改变形状——每一笔在落笔时就固定了自己的工具。

### 粗细行

一个滑杆，左侧实时显示当前值（形如 `4dp`），范围 **1～24 dp**，默认 4 dp。

### 动作行

| 按钮 | 动作 |
| --- | --- |
| 撤销 | 删除最后一笔 |
| 清空 | 清空全部笔画 |
| 截图 | 保存「完整屏幕 + 当前标注」为图片 |

<div class="sr-note">
<strong>没有「重做」。</strong>撤销是单向的；撤销后再画会开启新笔画。「清空」同样不可撤销。
</div>

## 「操作」模式

点表头行的「操作 ⇄」后，画布变成**触摸穿透**：你在屏幕上点按、滑动会正常传给下面的应用，方便一边演示一边讲解。此时工具条本身仍可点，画布会变成半透明。

点「绘制 ⇄」回到绘制模式。

<div class="sr-note">
<strong>切到「操作」会清空当前所有标注。</strong>这是有意设计——每次进入绘制模式都从干净的画布开始。想保留标注就先截图。
</div>

## 截图

点「截图」会保存一张包含完整屏幕内容与当前标注的 PNG：

- **保存位置**：`Pictures/ScreenRecorder`
- **文件名**：`标注_<毫秒时间戳>.png`
- **成功提示**：屏幕与标注已保存至 Pictures/ScreenRecorder

截图取自**当前录制的画面帧**，所以：

- 包含标注墨迹（墨迹属于被录制内容）
- 不包含标注工具条（工具条在排除图层上）
- 不包含悬浮球
- **不需要任何额外授权**，复用录制已有的采集链路

保存期间三个动作按钮会暂时忽略点击，避免重复触发。写入失败会自动回滚，不留半张坏图。

失败时的提示：

| 情况 | 提示 |
| --- | --- |
| 录制已结束 | 截图失败：录制已结束 |
| 取帧超时 | 截图失败：等待画面超时，请重试 |
| 其他 | 截图失败：… |

## 工具条不会被录进画面

在 Shizuku 模式下，标注工具条会被画到一个独立的、标记为「跳过截屏」的系统图层上，所以**讲解时观众看不到你的工具栏**，只看到标注本身。

Root 模式下不启用这层排除，工具条会出现在录制里。
