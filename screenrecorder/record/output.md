# 保存、暂停与恢复

## 文件保存在哪

| 类型 | 默认位置 |
| --- | --- |
| 视频 | `Movies/ScreenRecorder` |
| 音频（提取音频的结果） | `Music/ScreenRecorder` |
| 图片（标注截图） | `Pictures/ScreenRecorder` |

- **默认**：`Movies/ScreenRecorder`，录制结束会自动出现在系统相册里。
- **自定义**：在主页「保存位置」里通过系统文件选择器挑一个文件夹，授权会持久保存；点「使用默认」回到默认位置。
- 自定义文件夹**是否显示在系统相册里取决于系统索引**——有些第三方的文件管理器目录不会被媒体库扫描，但文件确实在那里。
- 视频工具箱的输出与录制使用同一个保存位置，原文件不动。

### 文件名

- 录制：`录屏_20260101_120000.mp4`（按录制开始时间命名）
- 标注截图：`标注_<时间戳>.png`
- 工具输出：`<原名>_<任务名>_<时间戳>.<扩展名>`

如果同名文件已经存在，应用会自动改用 `名字 (1).mp4`、`名字 (2).mp4`……**不会覆盖**你已有的文件。

### 保存到云盘之类的位置

如果你选的文件夹背后是云盘，录制会先暂存在应用内部，等录制结束（或下次打开应用）再搬进你选的目录。文件不会丢，只是要等一会儿才会出现在目标位置。

## 停止与保存

停止录制后，应用需要先合并音视频再写入文件，请等待「保存完成」的提示。

保存成功会显示路径，形如：

> 已保存：Movies/ScreenRecorder/录屏_20260101_120000.mp4

<div class="sr-note">
<strong>强制结束进程或设备断电不能保证视频完整。</strong>请尽量用正常的停止方式（通知栏、悬浮球、应用内）。保存失败时临时文件会保留，重新打开应用时有机会自动补登记。
</div>

### 保存失败时

保存失败会提示「保存失败：…」，并给出临时文件路径。可以尝试：

1. 重新打开应用，让它自动补登记。
2. 用文件管理器到应用的私有目录里找。

## 暂停与继续

录制中可以暂停：

| 入口 | 操作 |
| --- | --- |
| 通知栏 | 「暂停」/「继续」 |
| 悬浮球菜单 | 「暂停」/「继续」 |
| 悬浮工具栏 | 录制按钮 |
| 应用内 | 录制按钮 |

暂停时通知标题变成「录制已暂停」，悬浮球显示 `▶`。暂停期间不计入时长，恢复后继续写入同一个文件。

## 息屏行为

「控制与安全」里的「息屏后暂停录制」开关（默认关闭）：

> 息屏后录制暂停，亮屏后自动恢复。若息屏超过6分钟，将自动结束录制。

开启后，锁屏会暂停录制而不是继续消耗电量；超过 6 分钟则结束并保存。

## 长时间录制的稳定性

建议开启「保持录制稳定」的电池优化豁免。未开启时主页「参数预览」里会显示一条可点击的提示「录制可能被系统中断」+「开启豁免」。

## 录制中断了怎么办

如果录制因为应用被划掉、手机重启等原因中断，重新打开应用时会自动处理：

- 「移入 N 段暂存的录制」—— 把没搬完的录制放进你选的文件夹
- 「补登记 N 段录制到相册」—— 把相册里看不到的录制重新登记

## 录制失败时

| 情况 | 提示 |
| --- | --- |
| 启动失败 | 启动失败：… |
| 录制中出错 | 录制失败：… |
| 保存失败 | 保存失败：… |
| 高权限服务断开 | 高权限服务已断开 |

失败时状态会显示在主页与通知栏，并提供「查看」动作（如果已经产出了可播放的文件）。
