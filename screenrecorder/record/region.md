# 区域录制

只录屏幕上的一块区域，适合教程、演示局部操作、或者只想录某个窗口。

## 开启

主页「画面设置」里的「区域录制」开关，摘要写着「仅录制选定范围，修改下次录制生效」。打开后会出现「录制范围」入口，摘要显示当前范围，形如：

> 左 0% · 上 0% · 右 100% · 下 100%

范围用**百分比**表示，相对于旋转后的录制画面，从左上角开始量。

## 使用流程

1. 打开「区域录制」开关。
2. 点「开始录制」。应用会先要悬浮窗权限（区域选区要画在其他应用上层），已授权就直接进入选区界面。
3. 在选区界面上调整范围，确认后开始录制。
4. 停止方式与其他录制一致（通知栏 / 应用内 / 悬浮球）。

<div class="sr-note">
<strong>区域录制没有降级路径。</strong>没有悬浮窗权限就没有选区，应用不知道该录哪块画面，所以只能取消本次启动，提示「未授予悬浮窗权限，已取消启动录制」。这不像摄像头小窗那样可以关掉小窗继续录。
</div>

## 选区界面

选区是一个悬浮窗，屏幕上会同时出现：

- **选区外的遮罩**：黑色 70%，让选区内的画面显得更亮
- **选区边框**：4dp 描边，颜色取自当前主题
- **8 个白色手柄**：上下边画横线、左右边画竖线、四个角画 L 形折线，会跟着屏幕旋转一起转
- **两个圆形按钮**：直径 48dp，默认在选区下方，下方放不下时自动翻到选区上方。左边是 ✓（保存录制范围），右边是 ✗（取消范围编辑）

### 怎么调

| 操作 | 效果 |
| --- | --- |
| 拖边框或四角 | 改变大小（四角拖动保持比例，见下） |
| 拖选区内部 | 移动位置 |
| 点 ✓ | 保存范围并开始录制 |
| 点 ✗ | 放弃本次启动 |

- 选区外仍可正常操作手机；选区内部会接收拖动，不会点到下面的应用。
- 关闭范围编辑后选区即刻移除，不会留在屏幕上。
- 手柄的命中半径是 22dp（选区外扩 14dp 的范围都算），所以不用点得很准。
- 拖动过程中如果屏幕旋转了，当前拖动会立即取消，避免算出错误的位置。

## 在应用内编辑

不开始录制也能调范围：主页「录制范围」入口会打开一个对话框，里面是可拖拽的可视化编辑器。

- 八个手柄加整体移动，和悬浮选区一致。
- 中央有一个比例徽标，显示当前选区的宽高比（形如 `1.78 : 1`）。**点它**可以输入指定比例——两个输入框中间一个冒号，只接受数字与小数点。
- 底部按钮：「重置」（回到 0/0/100/100）与「保存」。
- 对话框里有一行提示：「在此页面切换应用可进一步进行调节。」——意思是切到别的应用后，悬浮选区仍然在，可以对着真实界面调。

### 比例输入的错误提示

| 情况 | 提示 |
| --- | --- |
| 宽或高不是有效正数 | 请输入有效的正数比例 |
| 比例换算后非法 | 请输入大于 0 的有效比例 |
| 超出允许范围 | 该比例无法在当前画面内满足最小选区要求 |

## 约束

范围本身有以下硬性约束，任何一条不满足都会报错「录制区域宽高至少为画面的 5%，边界须在 0～100% 内」：

| 项 | 约束 |
| --- | --- |
| 左、上 | 0～99% |
| 右、下 | 1～100% |
| 宽度 | 右 − 左 ≥ 5% |
| 高度 | 下 − 上 ≥ 5% |

也就是说**选区最小是画面的 5% × 5%**。

编辑器里还有两条行为规则：

- **拖四角只缩放一个比例**，所以角拖动永远不会把矩形拉变形；缩放系数会被夹在允许范围内。
- **拖边**只动那一条边，并保证最小边长 5%。

## 输出尺寸

输出视频尺寸取自选区在你设备上的**实际像素**（百分比换算到当前屏幕分辨率）。

某些设备的编码器对非标准尺寸支持有限——例如只接受 16 的倍数。超出时会在开始录制前报错，换个范围再试。

## 和「裁剪视频」的区别

区域录制在**采集阶段**就只取那块画面：文件本身就是小的，不掉帧也不浪费码率。

如果是已经录好的整屏视频只想留一部分，那是裁剪，属于视频编辑工具的范围——**本应用不提供时间轴剪辑**。

## 跨应用同步

选区确认后会写回设置，并带一个版本号。主页在恢复时会比对版本号，发现变化才覆盖，这样从悬浮球或磁贴改过的范围能正确同步回主页。
