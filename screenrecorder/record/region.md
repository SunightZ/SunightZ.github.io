# 区域录制

只录屏幕上的一块区域，适合教程、演示局部操作、或者只想录某个窗口。

## 开启

主页「画面设置」里的「区域录制」开关，说明写着「仅录制选定范围，修改下次录制生效」。打开后会出现「录制范围」入口，显示当前范围，形如：

> 左 0% · 上 0% · 右 100% · 下 100%

范围用**百分比**表示，相对于整个画面。

## 使用流程

1. 打开「区域录制」开关。
2. 点「开始录制」。应用会先要悬浮窗权限（选区要显示在其他应用上层），已授权就直接进入选区界面。
3. 在选区界面上调整范围，确认后开始录制。
4. 停止方式与其他录制一致（通知栏 / 应用内 / 悬浮球）。

<div class="sr-note">
<strong>区域录制没有降级路径。</strong>没有悬浮窗权限就没有选区，应用不知道该录哪块画面，所以只能取消本次启动，提示「未授予悬浮窗权限，已取消启动录制」。这不像摄像头小窗那样可以关掉小窗继续录。
</div>

## 选区界面

开始录制时会进入选区界面：

- 选区外面变暗，选区内保持正常
- 选区有一圈醒目的边框
- 边框上有 8 个白色手柄，四边各一个、四角各一个
- 下方有两个圆形按钮：左边 ✓（确认），右边 ✗（取消）

### 怎么调

| 操作 | 效果 |
| --- | --- |
| 拖边框或四角 | 改变大小 |
| 拖选区内部 | 移动位置 |
| 点 ✓ | 确认范围并开始录制 |
| 点 ✗ | 放弃本次启动 |

- 选区外仍可正常操作手机；选区内部会接收拖动，不会点到下面的应用。
- 关闭选区后它即刻消失，不会留在屏幕上。
- 拖动四角时**比例保持不变**，不会把矩形拉变形。

## 在应用内预先调整

不开始录制也能调范围：主页「录制范围」入口会打开一个编辑对话框。

- 拖动八个手柄或整体移动，和选区界面一致。
- 中间显示当前宽高比（形如 `1.78 : 1`）。**点它**可以输入指定比例，两个输入框中间一个冒号。
- 底部按钮：「重置」（回到整个屏幕）与「保存」。
- 对话框里有一行提示：「在此页面切换应用可进一步进行调节。」——切到别的应用后选区仍然在，可以对着真实界面调。

比例输入不合法时会提示，按提示改成有效数字即可。

## 范围限制

| 项 | 限制 |
| --- | --- |
| 边界 | 在 0～100% 之间 |
| 最小尺寸 | 宽和高都至少是画面的 5% |

超出限制时会提示「录制区域宽高至少为画面的 5%，边界须在 0～100% 内」。

## 输出尺寸

输出视频尺寸取自选区在你手机上的**实际像素**。

某些设备对非标准尺寸支持有限，超出时会在开始录制前提示，换个范围再试。

## 和「裁剪视频」的区别

区域录制在**录制时**就只取那块画面：文件本身就是小的，不浪费空间。

如果是已经录好的整屏视频只想留一部分，那是裁剪——**本应用不提供时间轴剪辑**。
