# 触摸可视化

把每一次触摸实时画在屏幕上，用于讲解操作、录制教学视频，或在演示时让观众看清手指落点。

<div class="sr-note">
<strong>需要 Root 或 Shizuku 权限，且是高级版功能。</strong>未激活时每次开启可体验 1 分钟。
</div>

它**不需要开始录制**就能单独使用，也可以从控制中心磁贴一键开关。

## 和「显示触摸位置」的区别

这两个功能名字很像，但不是一回事：

| | 触摸可视化 | 显示触摸位置 |
| --- | --- | --- |
| 位置 | 工具页的「触摸可视化」区块 | 主页「录制方式」里的开关 |
| 前提 | Root 或 Shizuku | 只在 Shizuku / Root 模式下出现 |
| 需要录制 | 不需要，随时可开 | 只在录制期间生效 |
| 外观 | 四种效果，颜色与大小可调 | 系统自带的小白点 |

想要好看的效果用触摸可视化；只想快速标注点按位置，用「显示触摸位置」更省事。

## 四种效果

在「触摸美化效果」下拉里选择：

| 效果 | 说明 |
| --- | --- |
| 光晕圆点（默认） | 柔光渐变，无硬边，最不打扰 |
| 涟漪扩散 | 扩散圆环加柔和核心 |
| 拖尾彗星 | 沿手指真实轨迹渐隐收尖，适合滑动演示 |
| 轨道光环 | 双环反向旋转，最有装饰性 |

## 颜色

「触摸标记颜色」提供七个选项：

| 选项 | 说明 |
| --- | --- |
| 跟随主题（默认） | 用当前主题的主色 |
| 靛蓝 / 青碧 / 琥珀 / 品红 / 紫罗兰 | 五种预设色 |
| 自定义 | 打开取色板自己选 |

选「自定义」会打开一个取色弹窗，标题「自定义触摸颜色」，按钮「取消」/「使用」。

预设色在浅色与深色背景下都做过对比度检查，两种主题下都看得清。

## 大小

「触摸标记大小」滑杆，范围 **4.0～24.0 dp**，默认 **10.0 dp**。

想要不打扰就调小，想在繁忙画面上也看得清就调大。

## 试用与限制

未激活高级版时：

> 未激活：每次开启可体验 1 分钟

1 分钟到点会提示「触摸可视化免费体验已达到 1 分钟，请激活高级版」并自动关闭。从控制中心磁贴启动也一样。

## 运行时的提示

| 情况 | 提示 |
| --- | --- |
| 启动成功 | 触摸可视化已开启 |
| 选了预设色 | 触摸可视化已开启 · `颜色名` |
| 既无 Root 也无 Shizuku | 触摸可视化需要 Root 或 Shizuku 权限，请先授予其一 |
| 缺少悬浮窗权限 | 缺少悬浮窗权限，无法显示触摸效果 |
| 权限不可用 | 无法读取触摸设备：请确认已授予 Root 或 Shizuku 权限 |
| 设备不支持 | 触摸读取库未加载（缺少本机库或设备架构不支持） |

开启后通知栏会有一条常驻通知「触摸可视化运行中」，带一个「停止」按钮。

## 从控制中心开关

「添加到控制中心」可以把「触摸可视化」磁贴放进控制中心。磁贴副标题显示「显示触摸位置」或「正在显示」，点击即开关。

关闭是立即生效的；开启时会先检查权限，缺什么就提示什么。
