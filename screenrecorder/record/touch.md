# 触摸可视化

把每一次触摸实时画在屏幕上，用于讲解操作、录制教学视频，或在演示时让观众看清手指落点。

<div class="sr-note">
<strong>需要 Root 或 Shizuku 权限，且是高级版功能。</strong>普通应用无法读取触摸设备节点，所以必须借特权进程。未激活时每次开启可体验 1 分钟。
</div>

它**不需要开始录制**就能单独使用，也可以从控制中心磁贴一键开关。

## 和「显示触摸位置」的区别

这两个功能名字很像，但不是一回事：

| | 触摸可视化 | 显示触摸位置 |
| --- | --- | --- |
| 位置 | 工具页的「触摸可视化」区块 | 主页「录制方式」里的开关 |
| 前提 | Root 或 Shizuku | 只在 Shizuku / Root 模式下出现 |
| 需要录制 | 不需要，随时可开 | 只在录制期间生效 |
| 外观 | 四种效果，颜色与大小可调 | 系统自带的小白点 |
| 实现 | 应用层读取触摸节点并自绘 | 执行系统 `settings` 命令打开 `show_touches` |

想要好看的效果用触摸可视化；只想快速标注点按位置，用「显示触摸位置」更省事。

## 四种效果

在「触摸美化效果」下拉里选择：

| 效果 | 说明 | 绘制特点 |
| --- | --- | --- |
| 光晕圆点（默认） | 柔光渐变，无硬边 | 径向渐变，最不打扰的一种 |
| 涟漪扩散 | 扩散圆环 + 柔和核心 | 两圈相位错开的圆环向外扩散 |
| 拖尾彗星 | 沿真实轨迹渐隐，适合滑动演示 | 多层渐隐拖尾，带一个白色针尖 |
| 轨道光环 | 双环反向旋转 | 外环与内环以不同速度反向旋转 |

所有标记都会在手指抬起后约 320 毫秒内淡出。

## 颜色

「触摸标记颜色」提供七个选项：

| 选项 | 色值 |
| --- | --- |
| 跟随主题（默认） | 取当前主题的主色 |
| 靛蓝 | `#4F6BED` |
| 青碧 | `#0E9E90` |
| 琥珀 | `#B87D12` |
| 品红 | `#E5457B` |
| 紫罗兰 | `#7C5CFC` |
| 自定义 | 由取色板选择，默认 `#4F6BED` |

选「自定义」会打开一个取色底部弹窗（标题「自定义触摸颜色」，按钮「取消」/「使用」）。

预设色的选取标准是：在浅色卡片（`#F7F7F7`）与深色卡片（`#242424`）上都满足 3:1 对比度——因为标记是画在未知内容之上的细形状，只在一种背景下好看的颜色会在另一半场景里显得坏掉。

## 大小

「触摸标记大小」滑杆，范围 **4.0～24.0 dp**，默认 **10.0 dp**，步进 0.5 dp。

默认值取在范围偏上的位置：最小档适合刻意稀疏的效果，但第一次使用应该在繁忙画面上也看得清，而不是要用户自己去放大。

## 触摸是怎么读到的

这部分是功能的根基，也是为什么需要特权：

- 一个原生库直接读 `/dev/input/event*` 的原始多点触控流。
- **只读不抢**：打开设备时不加 grab、也不创建虚拟输入节点，所以系统照常收到同一批触摸——这正是它能在手机正常使用时工作的原因。
- 触摸面板上报的坐标是它自己的单位，不是像素（一台 1080×2400 的手机可能上报 20224×44480）。应用把自己知道的真实屏幕尺寸传给原生层做线性换算。
- 识别触摸设备靠的是 `ABS_MT_SLOT` 是否存在——真正的多点触控面板会报告 slot 数量，按键或传感器节点不会。
- 最多同时跟踪 10 个触点、8 个设备。

承载它的特权服务与录制的特权服务**是两个独立进程**。这样关闭触摸可视化不会把正在进行的录制一起关掉，反之亦然。

## 试用与限制

未激活高级版时：

> 未激活：每次开启可体验 1 分钟

1 分钟到点会提示「触摸可视化免费体验已达到 1 分钟，请激活高级版」并自动关闭。这个计时由服务自身强制，从磁贴启动也绕不过。持有永久授权则不计时。

## 运行时的提示

| 情况 | 提示 |
| --- | --- |
| 启动成功（跟随主题或自定义色） | 触摸可视化已开启 |
| 启动成功（选了预设色） | 触摸可视化已开启 · `颜色名` |
| 既无 Root 也无 Shizuku | 触摸可视化需要 Root 或 Shizuku 权限，请先授予其一 |
| 缺少悬浮窗权限 | 缺少悬浮窗权限，无法显示触摸效果 |
| 特权不可用 | 无法读取触摸设备：请确认已授予 Root 或 Shizuku 权限 |
| 原生库未加载 | 触摸读取库未加载（缺少本机库或设备架构不支持） |
| 找不到触摸节点 | 无法读取触摸设备：未找到触摸节点，或当前权限不足 |
| 启动异常 | 无法启动触摸可视化：… |

## 运行时的通知

开启后会有一条常驻通知（低优先级）：

- 标题：触摸可视化运行中
- 正文：正在显示触摸位置
- 动作：停止

## 从控制中心开关

「添加到控制中心」可以申请把「触摸可视化」磁贴放进控制中心。磁贴副标题会显示「显示触摸位置」或「正在显示」，点击即开关。

关闭是立即生效的（不需要打开页面）；开启时会先检查悬浮窗权限与特权，缺什么就提示什么。

## 选择 Root 还是 Shizuku

应用会优先用 Root（可用时），否则用 Shizuku。这个选择在开启时确定一次，运行中不会切换。

探测 Root 的方式是实际执行 `id` 并检查输出里有没有 `uid=0`，而不是查询某个库的缓存状态——部分机型上后者会误报未授权。
