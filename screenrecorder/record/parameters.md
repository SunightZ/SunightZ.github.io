# 录制参数

主页「画面设置」与「声音设置」里的每一项，界面标签、默认值与可选范围都按实际界面列出。

<div class="sr-note">
<strong>录制期间参数固定。</strong>中途改分辨率、帧率、码率、声音开关都不会立刻生效，需要停止后重新开始——这样输出文件始终是一套一致的参数。
</div>

## 画面

| 参数 | 界面标签 | 默认值 | 可选范围 |
| --- | --- | --- | --- |
| 分辨率 | 分辨率滑块 / 画质预设 | 屏幕原始分辨率 | 128～7680 之间，宽高都必须是偶数 |
| 帧率 | 帧率（`范围` FPS） | 60 | 1 ～ 屏幕最高刷新率 |
| 码率 | 码率（`范围` Mbps） | 首次安装按画质档位，之后 12 | 1～100 Mbps |
| 编码格式 | H.265 / HEVC | 关（用 H.264） | H.264 / H.265 |
| 编码器 | 编码选择 | 硬件编码（推荐） | 硬件编码 / 软件编码 |
| 码率模式 | 码率模式（高级设置） | VBR | CBR / VBR |
| 录制方向 | 录屏方向 | 自动 | 自动 / 横屏 / 竖屏 |
| 动态帧率 | 动态帧率 | 关 | 开 / 关 |
| 动态码率 | 动态码率 | 关 | 开 / 关 |

### 分辨率怎么调

分辨率是一个百分比滑块，标签形如「分辨率 · 100%」，上下限小字标出当前可用范围：

- **100%** 就是屏幕的原始分辨率。
- **低于 100%** 按比例缩小，画面更小、文件更小、录制更流畅。
- **高于 100%** 是**超分录制**，会把画面放大。此时会显示一条黄字提示：

> 当前为超分录制（高于 100%），处理器性能不足时可能出现卡顿。建议按原分辨率录制，再用工具页面的「视频超分」对视频进行后期处理。

- 当前分辨率不被所选编码器接受时，滑块下方会显示红字提示，调整缩放比例即可。

### 帧率与码率

两个数字输入框。输入框上方的括号里会显示当前设备可用的范围；输入非法或超限时输入框描边变红。

帧率的上限是**屏幕支持的最高刷新率**（如 120 Hz 屏幕可到 120 FPS）。注意：

> 帧率是目标/上限，静态画面不保证持续生成这么多帧。

### 画质预设

下拉里的预设会**一次性改写分辨率、帧率、码率三项**：

| 预设 | 帧率 | 码率 |
| --- | --- | --- |
| 8K | 30 | 100 Mbps |
| 4K | 60 | 60 Mbps |
| 2K | 60 | 24 Mbps |
| 1080p | 60 | 12 Mbps |
| 720p | 60 | 8 Mbps |
| 原画 | 跟随屏幕 | 按最接近的档位 |

不确定选哪个就选「1080p」，兼顾清晰度与文件大小。

### 动态帧率与动态码率

按画面变化自动调整，静态画面下更省电、文件更小。两个开关配合工作，**优先调整帧率**。

> 界面上这两个开关都标注了「算法测试中，可能不稳定」。如果录制出现明显的帧率波动，先关掉它们。

### 编码格式怎么选

| | H.264 | H.265 / HEVC |
| --- | --- | --- |
| 同画质体积 | 较大 | 更小 |
| 兼容性 | 更好 | 老设备播放兼容性略差 |

不确定就保持 H.264。需要更小的文件、且播放端支持时再切 H.265。

## 声音

| 参数 | 界面标签 | 默认值 | 可选范围 |
| --- | --- | --- | --- |
| 系统声音 | 系统声音 | **开** | 开 / 关 |
| 麦克风 | 麦克风 | 关 | 开 / 关 |
| 麦克风降噪 | 麦克风降噪 | 关 | 开 / 关 |
| 采样率 | 采样率（高级设置） | 48000 Hz | 16000 / 22050 / 24000 / 32000 / 44100 / 48000 |
| 音频码率 | 音频码率（高级设置） | 128 kbps | 32～320 kbps |
| 声道 | 立体声 | 开（双声道） | 单声道 / 双声道 |
| 系统声音音量 | 系统声音（混音增益） | 100% | 0～200% |
| 麦克风音量 | 麦克风（混音增益） | 100% | 0～200% |

「系统声音」是唯一默认开启的开关。逐项说明见[声音与混音](/record/audio)。

## 方向与尺寸

- 「自动」方向在录制**开始时**确定，中途旋转屏幕不会改变输出方向。
- 横竖屏切换时画面会正确旋转铺满，不会缩成中间一条。
- 自定义宽高比与屏幕不一致时会拉伸适配。
