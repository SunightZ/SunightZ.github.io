# 悬浮球与悬浮工具栏

应用提供两套「不离开当前画面就能控制录制」的方式：系统级**悬浮球**（可跨应用）和页面内的**悬浮工具栏**（只在应用内）。两者互相独立，可以分别开关。

## 悬浮球

一个可拖动的小条，浮在其他应用上层，需要悬浮窗权限。

### 球面显示什么

| 状态 | 显示 |
| --- | --- |
| 待机 | `●` |
| 正在录制 | 计时（如 `02:31`） |
| 已暂停 | `▶` |
| 正在保存 | 保存中 |
| 启动过程中 | 启动中 |

### 手势

| 手势 | 效果 |
| --- | --- |
| 点一下（待机） | 开始录制 |
| 点一下（录制中或已暂停） | 打开控制菜单 |
| 长按 | 关闭悬浮球 |
| 拖动 | 移动到任意位置；拖到下方关闭区域松手即关闭 |

### 控制菜单

点一下悬浮球会展开一条竖向菜单，四个按钮：

| 按钮 | 动作 |
| --- | --- |
| 暂停 / 继续 | 暂停或继续录制（文字随状态变化） |
| 标注 | 打开屏幕标注（高级版） |
| 结束 | 停止并保存 |
| 收起 | 收起菜单 |

菜单会自动收起：点了任一项之后，或录制结束、保存完毕之后。

### 关闭区域

拖动悬浮球时，屏幕底部中央会出现一个圆形关闭区。拖进去后它会变红并轻微放大，松手即关闭悬浮球。

首次安装时会提示一次「拖动悬浮球到下方关闭区域可关闭」，之后不再提示。

## 悬浮球不会被录进画面

这是悬浮球最实用的一点：**用 Shizuku 或 Root 录制时，悬浮球与它的菜单不会出现在录制结果里**。

<div class="sr-note">
<strong>系统录屏模式下做不到这一点。</strong>普通悬浮窗会被系统录屏照实录下来。不想录进画面，就在录制前关掉悬浮球。
</div>

## 悬浮工具栏

主页「控制与安全」里的「启用侧边栏」**默认开启**。开启后页面右侧有一条竖向悬浮工具栏，四个按钮从上到下：

| 按钮 | 说明 |
| --- | --- |
| 悬浮球开关 | 开启或关闭悬浮球 |
| 触摸可视化 | 开启或关闭触摸效果 |
| 录制 | 开始 / 停止 / 继续录制，录制中会变红 |
| 拖动柄 | 上下拖动可移动工具栏位置 |

工具栏位置会记住，并限制在屏幕范围内。它与悬浮球独立：关掉悬浮球，工具栏照样能用。

## 悬浮菜单页

从控制中心磁贴启动、或点悬浮球菜单里的「标注」时，可能出现一个弹窗页：

- 普通状态：标题「小白录制」，副标题「选择要执行的操作」，两个按钮——「屏幕标注」与「关闭悬浮窗」。
- 需要解锁时：标题变成「该模式需解锁高级版」，内容换成功能对比图与「继续体验」/「前往购买」两个按钮。

## 启动失败时

| 情况 | 提示 |
| --- | --- |
| Shizuku 未启动或未授权 | 请先启动 Shizuku 并授权，授权后再启动悬浮球 |
| Root 未授权 | 启动悬浮球失败：请在管理器中授予 Root 权限 |
| 没有悬浮窗权限 | 未授予悬浮窗权限 |
| 悬浮球无法显示 | 无法显示悬浮窗：… |
