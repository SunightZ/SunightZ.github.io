# 悬浮球与悬浮工具栏

应用提供两套「不离开当前画面就能控制录制」的方式：系统级**悬浮球**（可跨应用）和页面内的**悬浮工具栏**（只在应用内）。两者互相独立，可以分别开关。

## 悬浮球

一个可拖动的小条，浮在其他应用上层，需要悬浮窗权限。

### 球面显示什么

| 状态 | 显示 |
| --- | --- |
| 待机 | `●` |
| 正在录制 | `mm:ss` 计时 |
| 已暂停 | `▶` |
| 正在保存 | 保存中 |
| 启动过程中 | 启动中 |

无障碍描述也会跟着变：录制中是「录制中 N 秒；点击展开录制菜单」，待机时是「开始录制；拖动调整位置」。

### 手势

| 手势 | 效果 |
| --- | --- |
| 点一下（待机） | 开始录制 |
| 点一下（录制中或已暂停） | 打开控制菜单 |
| 长按 | 关闭悬浮球 |
| 拖动 | 移动到任意位置；拖到下方关闭区域松手即关闭 |

长按关闭有防抖：正在启动、有待处理请求或刚点过不到 1 秒时不会触发。

### 控制菜单

菜单不是径向菜单，而是**一条竖向长条，水平居中对齐悬浮球当前位置**，四个按钮等分高度，各带手绘图标与中文标签：

| 顺序 | 标签 | 图标 | 动作 |
| --- | --- | --- | --- |
| 1 | 暂停 / 继续 | 双竖条 / 实心三角 | 暂停或继续录制（标签随状态变化） |
| 2 | 标注 | 铅笔 | 打开屏幕标注（高级版） |
| 3 | 结束 | 实心方块 | 停止并保存 |
| 4 | 收起 | 向下 V 形 | 收起菜单 |

菜单会自动收起：点了任一项之后，或录制结束、保存完毕之后。

### 关闭区域

拖动悬浮球时，屏幕底部中央会出现一个圆形关闭区：

- 常态是深灰底 + 白色 X 叉；拖动进入后变红并轻微放大，同时有一次轻触震动反馈
- 判定半径 42dp
- 无障碍描述是「拖入并松手关闭悬浮球」
- 首次安装时会提示一次「拖动悬浮球到下方关闭区域可关闭」，之后不再提示

## 悬浮球不会被录进画面

这是悬浮球最特别的一处：在 Shizuku 或 Root 模式下，悬浮球与它的菜单**不会出现在录制结果里**。

做法是把球与菜单的像素画进一个独立的、标记为「跳过截屏」的系统图层，而普通窗口本身设为完全透明。区域选区、标注工具条、更新提示也走同一套机制。

<div class="sr-note">
<strong>系统录屏模式下做不到这一点。</strong>普通悬浮窗会被系统录屏照实录下来。不想录进画面，就在录制前关掉悬浮球。
</div>

图层创建失败时会提示「排除录屏图层创建失败：…」或「Root 排除录屏图层创建失败：…」，此时悬浮球仍可用，只是会被录进画面。

## 悬浮工具栏

主页「控制与安全」里的「启用侧边栏」**默认开启**。开启后页面右侧有一条竖向悬浮工具栏（圆角 18dp），四个按钮从上到下：

| 按钮 | 提示文字 | 说明 |
| --- | --- | --- |
| 悬浮球开关 | 启动悬浮球 / 关闭悬浮球 | 直接开关系统悬浮球 |
| 触摸可视化 | 开启触摸可视化 / 关闭触摸可视化 | 开关触摸效果（高级版） |
| 录制 | 开始录制 / 启动中 / 停止录制 / 继续录制 / 正在保存 | 录制中图标变红 |
| 拖动柄 | 移动工具栏 | 上下拖动改变位置 |

工具栏位置会记住，并限制在屏幕范围内。它与悬浮球独立：关掉悬浮球，工具栏照样能用。

## 从悬浮球开始录制时会做什么

点悬浮球开始录制并不是简单地"开录"，它会走一遍和主页一致的检查：

1. 如果已经在录制，直接发停止。
2. 防抖：1 秒内重复点击、有待处理请求或正在启动时忽略。
3. 读取保存的录制配置；没有配置就提示「请先在主页设置录制参数」。
4. 按已拒绝的权限做降级处理。
5. Root / Shizuku 模式且没有有效高级版凭据时，弹「该模式需解锁高级版」。
6. 校验参数与设备编码器能力。
7. 开了区域录制就先显示选区；已授权悬浮窗时**不切页面**直接显示。
8. 需要系统录屏授权时才打开授权页；不需要时直接开始，避免闪一下透明页。

任何一步失败都会用一条 Toast 说明原因。

## 悬浮菜单页

从控制中心磁贴启动、或点悬浮球菜单里的「标注」时，可能出现一个透明对话框页：

- 普通状态：标题「小白录制」，副标题「选择要执行的操作」，两个按钮——「屏幕标注」与「关闭悬浮窗」。
- 需要解锁时：标题变成「该模式需解锁高级版」，内容换成实测对比图与「继续体验」/「前往购买」两个按钮。

## 启动失败时

| 情况 | 提示 |
| --- | --- |
| Shizuku 未启动或未授权 | 请先启动 Shizuku 并授权，授权后再启动悬浮球 |
| Shizuku 未就绪（另一种路径） | 启动悬浮球失败：请先启动Shizuku |
| Shizuku 权限未授予 | 启动悬浮球失败：未授予Shizuku权限 |
| Root 未授权 | 启动悬浮球失败：请在管理器中授予 Root 权限 |
| 没有悬浮窗权限 | 未授予悬浮窗权限 |
| 图层显示失败 | 无法显示悬浮窗：… |
