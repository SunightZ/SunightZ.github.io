# 声音与混音

录音分两路，各自独立开关、各自有增益，混音后编码为 AAC 写进视频。

## 两路音源

| 音源 | 说明 | 需要 |
| --- | --- | --- |
| 系统声音 | 录制手机内部正在播放的声音（游戏、视频、音乐） | 系统录屏模式：Android 10+ 的播放捕获；Shizuku / Root 模式：Android 13+ |
| 麦克风 | 录制环境声音、解说 | `RECORD_AUDIO` 权限；Shizuku / Root 模式仅麦克风需 Android 11+ |

两路可以只开一个，也可以同时开。**「系统声音」是唯一默认开启的开关。**

界面上「系统声音」的摘要会随系统版本变化：Android 10 及以上显示「录制应用播放的音频」，更低版本显示「需要 Android 10 及以上，当前系统不支持应用内录音捕获」并置灰。

## 两套系统声音实现

系统声音在两种模式下走完全不同的路径：

**系统录屏模式** —— 用 `AudioPlaybackCaptureConfiguration` 捕获本机播放的声音。

**Shizuku / Root 模式** —— 在特权进程里通过 AudioPolicy / LOOP_BACK_RENDER 捕获，**保留本机播放**：手机自己还在正常出声，不会为了录屏把手机录成静音。

实现上是填充 shell Application 与 AttributionSource 后创建双声道录音端点，麦克风也在同一个特权进程里采集，混音后编码 AAC，通过文件描述符写入应用文件。停止或失败时会释放 `AudioRecord` 并注销 AudioPolicy，**不会回退到会让本机静音的直采路径**。

共用的音频编码器不依赖 MediaProjection。

## 麦克风降噪

只在开启麦克风后出现。Android 把降噪做成音频效果（由设备的音频 HAL 实现）而不是一个库，所以没有额外编码步骤、也没有额外延迟。

打开后做两件事：

1. 给采集会话挂上系统的 `NoiseSuppressor` 效果；
2. 把采集源从 `MIC` 换成 `VOICE_RECOGNITION`——这是多数厂商跑自家降噪的语音调优输入路径，也是**设备不提供降噪效果时仍然有效**的那部分。

摘要文案会如实反映设备能力：

- 设备支持降噪效果：启用系统降噪效果，并改用语音识别音源
- 设备不提供：本机未提供系统降噪效果，将仅改用语音识别音源

降噪效果挂不上时不会让录制失败，只是没有效果。

## 编码参数

在主页「高级设置」里打开「精细调整」后可见：

| 参数 | 界面标签 | 默认值 | 可选值 |
| --- | --- | --- | --- |
| 采样率 | 采样率 | 48000 Hz | 16000 / 22050 / 24000 / 32000 / 44100 / 48000 Hz |
| 码率 | AAC 码率 · kbps（32～320） | 128 | 32～320 kbps |
| 声道 | 立体声 | 开（双声道） | 单声道 / 双声道 |

采样率读取时会就近吸附到受支持的六档之一，所以旧版本存下的值不会阻塞录制。超出范围的码率会明确报错「音频码率须为 32～320 kbps」。

## 混音增益

同样在「高级设置」的「混音增益」组里，两路各有自己的滑块：

| 音源 | 范围 | 默认值 |
| --- | --- | --- |
| 系统声音 | 0～200% | 100% |
| 麦克风 | 0～200% | 100% |

滑块刻度标着 `0%` / `100% · 原始` / `200%`。**增益不修改手机本身的播放音量**——它只影响写进文件的那一路。

两路相加后限幅，所以增益过高会削波失真。只开一路时，把它调到 200% 通常是安全的；两路都开且都在 200%，很容易听到破音。

如果两路都没开，「混音增益」组显示「开启系统声音或麦克风后，可在此调整各自增益。」

<div class="sr-note">
<strong>回声提示：</strong>用扬声器播放声音、同时开麦克风录音，会产生回声与重复音。界面在两个开关都打开时也会提示「同时录制系统声音和麦克风时建议佩戴耳机，减少回声。」建议戴耳机录，或者只开一路。
</div>

## 录不到声音时

1. 确认对应开关是开着的，并已授予录音权限（系统设置 → 应用 → 权限）。
2. 有些应用在自身策略里禁止被捕获（受保护音频），这类内容系统不允许录，属于系统限制。
3. Shizuku / Root 模式下确认系统版本满足要求（系统声音 Android 13+，仅麦克风 Android 11+），不满足时应用会明确报错。
4. 检查增益是否被调到 0。

## 录制中的音频通知

录制通知的标题会在开启降噪时追加后缀「· 降噪」，例如「正在录制 · 降噪」。暂停时通知动作变成「继续」与「停止并保存」。
