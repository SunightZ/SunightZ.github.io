# 声音与混音

录音分两路，各自独立开关、各自有音量，录完写进视频。

## 两路音源

| 音源 | 说明 | 需要 |
| --- | --- | --- |
| 系统声音 | 录制手机内部正在播放的声音（游戏、视频、音乐） | 系统录屏模式：Android 10+；Shizuku / Root 模式：Android 13+ |
| 麦克风 | 录制环境声音、解说 | 录音权限；Shizuku / Root 模式需 Android 11+ |

两路可以只开一个，也可以同时开。**「系统声音」是唯一默认开启的开关。**

界面上「系统声音」的说明会随系统版本变化：Android 10 及以上显示「录制应用播放的音频」，更低版本会置灰并说明不支持。

<div class="sr-note">
<strong>用 Shizuku 或 Root 录系统声音时，手机本身照常出声。</strong>不会为了录屏把手机变成静音。
</div>

## 麦克风降噪

只在开启麦克风后出现。打开后应用会启用手机自带的降噪能力，并改用更适合人声的输入方式。

说明文字会如实反映你的设备：

- 设备支持降噪：启用系统降噪效果，并改用语音识别音源
- 设备不提供：本机未提供系统降噪效果，将仅改用语音识别音源

设备不支持时**不会影响录制**，只是没有降噪效果。

## 音质参数

在主页「高级设置」里打开「精细调整」后可见：

| 参数 | 界面标签 | 默认值 | 可选值 |
| --- | --- | --- | --- |
| 采样率 | 采样率 | 48000 Hz | 16000 / 22050 / 24000 / 32000 / 44100 / 48000 Hz |
| 码率 | 音频码率 | 128 kbps | 32～320 kbps |
| 声道 | 立体声 | 开（双声道） | 单声道 / 双声道 |

不确定就保持默认。想省空间可以把码率降到 96 或 64 kbps；想音质更好可以提到 192 或 256 kbps。

## 两路音量

同样在「高级设置」的「混音增益」组里，两路各有自己的滑块：

| 音源 | 范围 | 默认值 |
| --- | --- | --- |
| 系统声音 | 0～200% | 100% |
| 麦克风 | 0～200% | 100% |

滑块刻度标着 `0%` / `100% · 原始` / `200%`。**调整不会改变手机本身的播放音量**——只影响写进视频的那一路。

音量调太高会破音。只开一路时，调到 200% 通常是安全的；两路都开且都在 200%，很容易听到失真。

如果两路都没开，「混音增益」组会提示先开启声音来源。

<div class="sr-note">
<strong>回声提示：</strong>用扬声器播放声音、同时开麦克风录音，会产生回声与重复音。界面在两个开关都打开时也会提示「同时录制系统声音和麦克风时建议佩戴耳机，减少回声。」建议戴耳机录，或者只开一路。
</div>

## 录不到声音时

按顺序排查：

1. 确认对应开关是开着的，并已授予录音权限（系统设置 → 应用 → 权限）。
2. 有些应用会禁止自己的声音被录制（例如部分音乐、视频应用），这类内容属于系统限制。
3. Shizuku / Root 模式下确认系统版本满足要求（系统声音 Android 13+，仅麦克风 Android 11+）。
4. 检查音量滑块是不是被调到了 0。
