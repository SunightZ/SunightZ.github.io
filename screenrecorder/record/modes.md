# 三种录制方式

「小白录制」有三种录制方式，在主页「录制方式」里用两个开关选择：

| 开关组合 | 模式 | 需要什么 |
| --- | --- | --- |
| 都关 | **系统录屏** | 每次开始确认一次系统录屏授权 |
| 只开 Shizuku | **Shizuku** | 已安装并启动 Shizuku，且已授权本应用 |
| 只开 Root | **Root** | 设备已 Root，并在 Root 管理器里授权 |
| 都开 | 无效组合 | 应用提示「旧配置中的录制方式冲突，请重新选择。」 |

<div class="sr-note">
<strong>完整版功能。</strong>Shizuku 与 Root 录制只在完整版里提供；精简版只有系统录屏，两个开关不出现。三种方式都支持音频、区域录制、悬浮球、屏幕标注与视频工具箱。
</div>

## 系统录屏

**默认方式，什么都不用额外准备。**

点击开始录制后，系统会弹出录屏授权确认框，确认后开始。

**代价**：授权只对本次有效，每次开始都要确认一次。这是 Android 的系统机制，不是应用可以绕过的。

**系统声音**：Android 10 及以上可用。

## Shizuku

装好 Shizuku 并授权本应用后，录制**不再需要每次确认系统录屏弹窗**，点击即开始。

### 版本要求

| 能力 | 最低版本 |
| --- | --- |
| 仅麦克风 | Android 11 |
| 系统声音 | Android 13 |

不满足时应用会明确提示，不会静默降级：

> 保留本机播放的 Shizuku 系统音频需要 Android 13+

> Shizuku 音频捕获需要 Android 11 或以上；Android 10 可使用无声录制或普通录屏模式

Android 11 上录麦克风时**请先解锁屏幕再启动**。

### 前置准备

主页选中 Shizuku 后会显示说明与两个链接：

> 请先启动 Shizuku。系统声音需 Android 13+，麦克风需 Android 11+。

- 「Shizuku 激活教程」—— 打开 B 站教程视频
- 「下载 Shizuku」—— 指向 Shizuku 官方安装包

## Root

由系统级权限录制，**高帧率下更稳**，且录制过程不依赖应用本身：

- 应用被划掉或被杀，录制照样正常结束并保存
- 文件直接写进你选的目录，并自动出现在相册里

选中 Root 后会显示：

> 使用 Root 管理器授权；无需系统录屏授权。

### 性能差异

同一台设备、同一段内容、相同参数的实测对比：

| 指标 | 系统录制 | Shizuku | Root |
| --- | --- | --- | --- |
| 每帧 CPU 耗时 | 8.89 ms | 6.40 ms | 6.20 ms |
| 超预算帧 | 1.87% | 1.27% | 1.25% |
| 掉帧 | 1.70% | 1.45% | 1.24% |

数值会随设备与负载变化，**负载越高、帧率越高，差距越明显**。详见[实测数据](/premium/benchmark)。

## 显示触摸位置

选中 Shizuku 或 Root 后，「录制方式」区块会多出一个「显示触摸位置」开关：

> 录制时显示系统小白点，结束后关闭

录制时屏幕上会出现系统的点按反馈小白点，停止后自动关闭。

<div class="sr-note">
<strong>如果应用被强制结束</strong>，这个开关可能停在打开状态，需要手动到「开发者选项」里关掉「显示点按操作反馈」。
</div>

想要更好看的触摸效果（四种样式、可调颜色与大小），用[触摸可视化](/record/touch)，它是独立开关，不需要开始录制。

## 该选哪一种

| 你的情况 | 建议 |
| --- | --- |
| 偶尔录一下屏幕，不想折腾 | 系统录屏 |
| 常录游戏，要 120 FPS，不想每次点系统弹窗 | Shizuku |
| 需要长时间录制、要求最稳 | Root |
| 需要录制时显示点按操作 | 完整版 + Shizuku 或 Root |

## 失败时怎么办

- **Shizuku 模式报错**：部分机型的系统实现有差异。失败时应用会明确提示，可以取消该选项改用系统录屏。
- **Root 模式报错**：确认已在 Root 管理器里授予本应用权限。
- **受保护内容录出来是黑屏**：部分应用的版权视频、支付页、银行类界面系统不允许被录制，这是系统限制，任何录屏应用都一样。
