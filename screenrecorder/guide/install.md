# 安装与首次启动

## 环境要求

| 项目 | 要求 |
| --- | --- |
| 系统 | Android 10（API 29）及以上 |
| 架构 | arm64-v8a |
| Shizuku 采集（完整版） | 需要已安装并启动 Shizuku；系统声音需 Android 13+，仅麦克风需 Android 11+ |
| Root 采集（完整版） | 需要设备已 Root，并在 Root 管理器里授权本应用 |
| 存储 | 录制文件默认写入 `Movies/ScreenRecorder` |

## 安装

1. 下载 APK 并安装。系统可能会提示「未知来源」，按提示允许即可。
2. 打开应用。首次进入会展示《隐私政策》，逐条说明会处理哪些信息；点「同意并继续」进入主页。
3. 应用会提示「保持录制稳定」：开启电池优化豁免，长时间录制不容易被系统中断。可以稍后再开。
4. 首次进入会播放一遍四步引导（见下），看完后有一次彩带庆祝动画。

## 首次启动会做什么

安装后第一次打开，应用会做三件你可能察觉得到的事：

### 1. 按设备能力收敛默认参数

应用会向设备的硬件编码器要一份实际支持的组合，把默认的分辨率、帧率、码率收敛到受支持的最高一档（先尺寸、再帧率、最后码率）。调整完成后会提示：

> 已按设备编码能力调整录制参数：`{宽}×{高}` · `{帧率}` FPS

这一步只在**首次安装**时执行一次，之后你的手动设置不会被覆盖。详见[设备编码器能力](/record/capabilities)。

### 2. 四步引导

引导用一个全屏蒙版加聚光挖孔，依次指向四个位置，共四步：

| 步骤 | 标题 | 正文 | 按钮 |
| --- | --- | --- | --- |
| 1 | 菜单 | 可以在这里切换主题、加入社区、激活高级版。 | 下一步 |
| 2 | 录制方式 | 默认使用系统录屏；启用 Shizuku 或 Root 可获得更高性能。 | 下一步 |
| 3 | 全新导航栏 | 录制、处理、查看自由切换。 | 下一步 |
| 4 | 悬浮工具栏 | 开始或停止录制、唤起悬浮球，启用触摸可视化；拖动把手可以移动位置。 | 开始使用 |

前 3 步额外提供「跳过」，第 2 步起提供「上一步」。点「开始使用」结束引导（系统动画开启时播放彩带庆祝）；点「跳过」则不播放。引导是否已读记在本机，**不会因为版本更新重播**。

### 3. 两段后台自愈

启动时会在后台检查两类遗留文件，有结果时提示：

- **暂存的录制**：上一次录制因为保存位置是云盘等没有文件系统路径的提供方，文件被暂存在应用目录里，这次启动把它搬进你选的文件夹 → 提示「移入 N 段暂存的录制」。
- **漏登记的录制**：文件在磁盘上但系统媒体库没有记录（例如录制进程登记时应用已被杀掉），应用把它补登记进相册 → 提示「补登记 N 段录制到相册」。

两段检查都跳过 5 秒内还在写入的文件，补登记只看 7 天内的文件、最多 20 个。详见[保存、暂停与恢复](/record/output)。

## 首次录制的完整流程

1. 在主页确认「参数预览」里的分辨率、帧率、编码与声音开关。
2. 点「开始录制」。
3. 弹窗会先说明要申请的权限，点「继续授权」后系统弹窗才出现——**权限说明不是系统弹窗**，是应用提前解释这个权限用来做什么。
4. 确认系统录屏授权（选「立即开始」）。
5. 通知栏出现录制中的常驻通知，计时开始。
6. 停止：点通知栏的停止按钮、或应用内、或悬浮球、或悬浮工具栏。

<div class="sr-note">
<strong>拒绝过的权限不会再弹窗。</strong>如果你在系统弹窗里明确拒绝过某个权限（例如录音），应用会记住：之后直接按说明里的降级方式继续录制（关掉摄像头小窗、改为无声录制等），并提示一次；想重新开启，到系统设置的权限页打开即可，应用会自动恢复询问流程。
</div>

## 关于启动音效

「启动音效」提供开关与六种内置音效：哎呦我去、冰冰冰、叹气、哇啊哦、哇哦、呦吼吼，默认「哎呦我去」。开关与选择会自动保存，从控制中心启动同样生效。录制启动成功后播放，最长 5 秒，停止录制时停止播放。

> 用扬声器播放提示音时，麦克风可能把它一起录进去；介意的话用耳机。

详见[摄像头小窗与启动音效](/record/extras#启动音效)。

## 控制中心磁贴

可以把「屏幕录制」加到控制中心，之后下拉就能快速开始：

- 首次使用请先在主页配置并启动一次，磁贴会沿用上次的参数。
- 完整版用 Shizuku 时，磁贴点击直接开始，不打开主页；Shizuku 未运行或未授权时会提示处理。
- 普通模式仍会打开授权流程，需要确认一次系统录屏权限。
- 「磁贴启动悬浮菜单」打开后，磁贴改为唤起悬浮球菜单而不是直接开始录制。

磁贴副标题会跟随状态变化：未录制时显示「开始录制」，录制中显示「录制任务进行中」，停止时短暂显示「正在保存」。

添加磁贴有两个入口：主页「控制与安全」里的「添加到控制中心」，或到控制中心的编辑页手动拖入。前者在 Android 13 及以上会直接弹出系统确认框，更低版本只能手动添加。
