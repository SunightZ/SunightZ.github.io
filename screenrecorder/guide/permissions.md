# 权限说明

应用只在你要用某个功能时才申请对应权限，不会在同意隐私政策的瞬间集中申请。拒绝任何一项只影响对应功能，其余功能照常可用。

## 逐条说明

| 权限 | 用来做什么 | 什么时候申请 |
| --- | --- | --- |
| 屏幕录制（系统录屏授权） | 录屏本身 | 每次开始录制时由系统弹窗确认，授权只对本次会话有效 |
| 麦克风 `RECORD_AUDIO` | 开启「麦克风」时录入环境声音 | 该开关开启、录制开始时 |
| 相机 `CAMERA` | 开启「前置摄像头」时显示摄像头小窗 | 该开关开启、录制开始时 |
| 读取视频 `READ_MEDIA_VIDEO`（Android 13+）/ `READ_EXTERNAL_STORAGE`（Android 12 及以下） | 把录制结果写进你选择的文件夹；读取你选中的视频供工具与播放使用 | 进入相册、使用视频工具箱时 |
| 悬浮窗 `SYSTEM_ALERT_WINDOW` | 悬浮球、区域选区、摄像头小窗显示在其他应用上层 | 启用对应功能时，跳系统设置页开启 |
| 通知 `POST_NOTIFICATIONS` | 录制中、暂停、保存完成的常驻通知 | Android 13+ 首次开始录制时 |
| 忽略电池优化 | 避免长时间录制被系统中断 | 你主动点「去开启」时 |
| 网络 `INTERNET` | 只有一处：首次使用视频工具箱时下载 FFmpeg 运行库 | 首次使用视频工具箱 |

<div class="sr-note">
<strong>悬浮球、选区与摄像头小窗都是普通悬浮窗，会出现在录制画面里。</strong>不想录进画面，就不要在录制时开启它们。
</div>

## 拒绝之后会怎样

应用把「明确拒绝」和「还没问过」分开处理：

- **还没问过**：先弹一段说明（讲清这个权限用来做什么），你点「继续授权」后才出现系统弹窗。
- **明确拒绝过**：不再重复弹窗，直接按说明里的降级方式继续录制，并提示一次结果。例如
  - 拒绝相机 → 不显示摄像头小窗，照样录屏；
  - 拒绝录音 → 改为无声录制；
  - 拒绝通知 → 照常录制，但通知栏看不到控制按钮（可用悬浮球停止）。

提示会合并成一条（例如「相机、录音权限未授予（可在系统设置中开启）」），一次录制最多提示一次。

## 想重新开启权限

到「系统设置 → 应用 → 小白录制 → 权限」里打开对应权限即可；返回应用后会立刻恢复，不需要卸载重装。应用不会自己跳系统设置页去骚扰你，只在提示里说明去哪里开。

## 撤销之后的影响

| 撤销的权限 | 影响 |
| --- | --- |
| 屏幕录制授权 | 无法录制（授权本来就是每次确认） |
| 麦克风 / 相机 | 对应开关不可用 |
| 悬浮窗 | 悬浮球、区域选区、摄像头小窗不可用 |
| 网络 | 视频工具箱首次下载无法完成，其余功能不受影响 |
