# 权限说明

应用只在你要用某个功能时才申请对应权限，不会在同意隐私政策的瞬间集中申请。拒绝任何一项只影响对应功能，其余功能照常可用。

## 逐条说明

| 权限 | 用来做什么 | 什么时候申请 |
| --- | --- | --- |
| 屏幕录制 | 录屏本身 | 每次开始录制时由系统弹窗确认，授权只对本次有效 |
| 麦克风 | 开启「麦克风」时录入环境声音 | 该开关开启、录制开始时 |
| 相机 | 开启「前置摄像头」时显示摄像头小窗 | 该开关开启、录制开始时 |
| 读取视频 | 把录制结果写进你选择的文件夹；读取你选中的视频供工具与播放使用 | 进入相册、使用视频工具箱时 |
| 悬浮窗 | 悬浮球、区域选区、摄像头小窗显示在其他应用上层 | 启用对应功能时，跳系统设置页开启 |
| 通知 | 录制中、暂停、保存完成的常驻通知 | Android 13+ 首次开始录制时 |
| 忽略电池优化 | 避免长时间录制被系统中断 | 你主动点「去开启」时 |
| 网络 | 只有一处：首次使用视频工具箱时下载运行库 | 首次使用视频工具箱 |

<div class="sr-note">
<strong>悬浮球、选区与摄像头小窗都是普通悬浮窗，会出现在录制画面里。</strong>不想录进画面，就不要在录制时开启它们。
</div>

## 权限说明弹窗长什么样

应用不会直接把系统弹窗甩给你。第一次申请某个权限前，会先弹一个标题为「权限说明」的对话框，按钮是「取消」/「继续授权」，正文说明这个权限用来做什么、拒绝了会怎样：

| 权限 | 说明正文 |
| --- | --- |
| 相机 | 相机权限：用于在录制期间显示前置摄像头悬浮预览。相机仅在录制过程中使用，不会在其他时间访问。拒绝后仍可录制屏幕，但前置摄像头预览不可用。 |
| 录音 | 录音权限：用于录制已选中的系统声音或麦克风声音。Android 在系统声音捕获时也要求此权限，仅在录制期间使用。拒绝后无法录制声音，本次会改为无声继续录制。 |
| 通知 | 通知权限：用于在通知栏展示录制状态、计时和停止按钮。拒绝后仍可录制，但通知栏控制可能不可见。 |
| 悬浮窗 | 悬浮窗权限：区域选区与摄像头小窗都需要显示在其他应用的上层。点击「继续授权」去系统设置里允许，返回后开始录制。 |
| 悬浮球 | 悬浮窗权限：用于在其他应用上方显示可拖动的录制控制菜单，方便开始或停止录制。拒绝不影响主页录制功能。请在接下来的系统设置中允许显示在其他应用上层。 |
| 流体云 | 流体云通知需要开启本应用的实时通知权限：点击「继续授权」后，在系统的通知设置中允许小白录制发送实时通知（部分机型称为「实时通知」或「流体云」），返回后开关即可生效。 |
| 相册 | 相册页面需要读取设备中的视频，用于显示视频列表、生成缩略图和调用系统播放器打开。<br><br>本应用不会上传这些视频，也不会读取与视频无关的文件。你也可以拒绝，拒绝后仅相册页面不可用，录屏与视频工具不受影响；拒绝后不会再重复询问，可在系统设置中开启。 |

## 拒绝之后会怎样

应用把「明确拒绝」和「还没问过」分开处理：

- **还没问过**：先弹一段说明（讲清这个权限用来做什么），你点「继续授权」后才出现系统弹窗。
- **明确拒绝过**：不再重复弹窗，直接按说明里的降级方式继续录制，并提示一次结果。

### 降级方式与提示

| 被拒权限 | 降级行为 | 提示 |
| --- | --- | --- |
| 相机 | 不显示摄像头小窗，照样录屏 | 相机权限未授予：已继续录制屏幕，但前置摄像头预览不可用 |
| 录音 | 改为无声录制 | 录音权限未授予：无法录制声音，本次已改为无声继续录制 |
| 通知 | 照常录制，但通知栏看不到控制按钮（可用悬浮球停止） | 通知权限未授予：已继续录制，但通知栏控制可能不可见 |
| 悬浮窗（区域录制） | **无法降级**，取消本次启动 | 未授予悬浮窗权限，已取消启动录制 |
| 悬浮窗（摄像头小窗） | 不显示小窗，照常录制 | 未授予悬浮窗权限，本次录制不显示摄像头小窗 |

多条同时被拒时会合并成一条，例如：

> 相机、录音权限未授予，已按说明降级继续录制（可在系统设置中开启）

一次录制最多提示一次。如果某条权限是**之前就拒绝过**的，后缀会变成：

> （已拒绝过，不再弹窗询问；可在系统设置中开启）

<div class="sr-note">
<strong>区域录制是个例外。</strong>没有悬浮窗权限就没有选区，应用不知道该录哪块画面，所以只能取消启动——这不像摄像头小窗那样可以降级继续。
</div>

## 相册权限

相册是唯一会长期持有权限的页面。

首次进入相册时会先解释用途再弹系统窗。如果你明确拒绝过，页面会改为显示「已拒绝访问视频权限」，正文说明系统不会再弹窗，并给一个「去系统设置」按钮——在系统设置里打开后返回即可，相册立刻恢复。

## 想重新开启权限

到「系统设置 → 应用 → 小白录制 → 权限」里打开对应权限即可；返回应用后会立刻恢复，不需要卸载重装。应用不会自己跳系统设置页去骚扰你，只在提示里说明去哪里开。

## 撤销之后的影响

| 撤销的权限 | 影响 |
| --- | --- |
| 屏幕录制授权 | 无法录制（授权本来就是每次确认） |
| 麦克风 / 相机 | 对应开关不可用 |
| 悬浮窗 | 悬浮球、区域选区、摄像头小窗不可用 |
| 通知 | 录制照常，但看不到通知栏控制 |
| 读取视频 | 相册页面不可用，视频工具箱选文件受限 |
| 网络 | 视频工具箱首次下载无法完成，其余功能不受影响 |
| Shizuku | Shizuku 模式无法启动，可改用系统录屏 |
