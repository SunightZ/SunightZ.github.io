# 保存位置与相册

## 保存位置

- **默认**：`Movies/ScreenRecorder`，录制结束会自动登记到系统相册。
- **自定义**：在「保存位置」里通过系统文件选择器挑一个文件夹，授权会持久保存；点「恢复默认」回到 `Movies/ScreenRecorder`。
- 自定义文件夹**是否显示在系统相册里取决于系统索引**——有些第三方的文件管理器目录不会被媒体库扫描，但文件确实在那里。
- 视频工具箱的输出与录制使用同一个保存位置，原文件不动。

<div class="sr-note">
<strong>保存失败怎么办：</strong>停止录制后应用要合并音视频再写入文件，请等「保存完成」提示。强制结束进程或设备断电不能保证 MP4 完整；保存失败时临时文件会保留在应用私有目录的 recordings 里，重新打开应用时有机会自动补登记。
</div>

## 相册

应用内置相册页，按录制时间列出本机视频。

| 功能 | 说明 |
| --- | --- |
| 列表 / 网格 | 两种排布，网格下可调缩略图大小 |
| 排序 | 时间、大小、时长等，可升序或降序 |
| 信息 | 分辨率、时长、大小、帧率等，可显示或隐藏字段 |
| 播放 | 调用系统默认播放器打开 |
| 分享 | 通过系统分享面板发送 |
| 重命名 / 删除 | 直接对文件操作；删除失败通常是系统未授予文件操作权限 |
| 下拉刷新 | 手动重新扫描；录制完成后进入相册会自动刷新 |

## 权限

相册需要读取视频权限：

- Android 13 及以上：`READ_MEDIA_VIDEO`
- Android 12 及以下：`READ_EXTERNAL_STORAGE`

首次进入相册时，应用会先解释这个权限的用途，然后才弹系统授权窗。**如果你明确拒绝过，之后不会再重复弹窗**：页面会改为提示「已拒绝访问视频权限」，并给一个「去系统设置」按钮——在系统设置里打开后返回即可，相册立刻恢复。
