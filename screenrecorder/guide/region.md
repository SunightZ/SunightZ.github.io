# 区域录制

只录屏幕上的一块区域，适合教程、演示局部操作、或者只想录某个窗口。

## 使用流程

1. 在主页「画面设置」里打开**区域录制**。
2. 点开始录制。应用会先要悬浮窗权限（区域选区要画在其他应用上层），已授权就直接进入选区界面。
3. 在选区界面上调整范围，确认后开始录制。
4. 停止方式与其他录制一致（通知栏 / 应用内 / 悬浮球）。

## 选区怎么调

- 拖动边框与四角改变大小，拖动内部移动位置。
- 选区外仍可正常操作手机，选区内部会接收拖动，不会点到下面的应用。
- 关闭范围编辑后选区即刻移除，不会留在屏幕上。

## 需要注意

- **没有悬浮窗权限就无法选区**，这时应用会提示「未授予悬浮窗权限，已取消启动录制」；区域录制不像摄像头小窗那样可以降级继续——没有选区就不知道该录哪块。
- 选区与悬浮球都是普通悬浮窗，会出现在录制画面里。
- 输出视频尺寸取自选区在你设备上的实际像素；某些设备的编码器对非标准尺寸支持有限，超出时会报错，换个范围再试。
- 录制期间参数固定，想改选区需要停止后重新开始。

## 和「裁剪视频」的区别

区域录制在**采集阶段**就只取那块画面，文件本身就是小的，不掉帧也不浪费码率；如果是已经录好的整屏视频只想留一部分，那是裁剪，属于视频编辑工具的范围，本应用不提供时间轴剪辑。
