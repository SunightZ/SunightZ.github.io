# 界面导览

应用是单 Activity + Compose，主体是三个可左右滑动的页面：**主页 / 工具 / 相册**，由底部导航栏切换。

- 窄屏：底部一条「液态玻璃」导航栏，宽度上限 300dp，高光会随机身倾斜轻微变化。
- 宽屏：导航栏改为左侧的 NavigationRail；屏幕宽度 ≥ 1200dp 时侧栏展开显示文字，否则只显示图标。
- 平板布局（宽度 ≥ 600dp）：内容区宽度上限 960dp。

<div class="sr-note">
<strong>深色模式下主页标题会变成「小黑录制」</strong>——浅色时是「小白录制」，这是同一处代码按当前主题取的字符串。
</div>

## 主页

顶部右侧有两个按钮：B 站图标（打开开发者主页）和菜单（更多）。菜单里有「更改主题」「加入 QQ 群」「打开酷安主页」，未激活高级版时还会多出一项「解锁高级版」。

页面从上到下依次是这些区块：

### 参数预览

把当下会用到的参数一次性摊开，改完立刻反映出来：

- 左侧是分辨率（`宽 × 高`）与右侧帧率（`FPS`）
- 一排标签：录制方式（系统录制 / Shizuku / Root / 请选择录制方式）、编码格式（H.264 / H.265）、码率（`N Mbps`）、声音（系统 + 麦克风 / 系统声音 / 麦克风 / 无声），开了麦克风降噪时额外显示「降噪」
- 未开启电池优化豁免时，会显示一条可点击的提示「录制可能被系统中断」+「开启豁免」

### 录制方式

两个开关（Shizuku / Root）加一句当前模式的说明。两个都关时是系统录屏；都开是无效组合，应用会提示「旧配置中的录制方式冲突，请重新选择。」并给出「使用系统录屏」按钮。

选中 Shizuku 或 Root 后，这里会多出一个「显示触摸位置」开关。详见[三种录制方式](/record/modes)。

### 画面设置

区域录制、前置摄像头、录屏方向、编码选择（硬件 / 软件）、画质预设、分辨率滑块、帧率与码率输入框、动态帧率、动态码率、H.265 开关，以及一个「设备编码器能力」入口。逐项说明见[录制参数](/record/parameters)。

### 声音设置

系统声音、麦克风两个开关；只开麦克风时多出「麦克风降噪」；两个都开时提示建议佩戴耳机。详见[声音与混音](/record/audio)。

### 高级设置

默认折叠，打开「精细调整」后出现三组：

- **视频参数**：码率模式（CBR / VBR）
- **音频参数**：采样率、AAC 码率、立体声开关
- **混音增益**：系统声音与麦克风各自的增益滑块（刻度为 `0%` / `100% · 原始` / `200%`）

### 控制与安全

「添加到控制中心」、流体云通知（仅 Android 16+ 显示）、「磁贴启动悬浮菜单」、「息屏后暂停录制」、「启用侧边栏」，以及「悬浮窗设置」（大小、不透明度、圆角、颜色）。详见[控制与安全](/settings/control)。

### 保存位置

显示当前保存路径，提供「使用默认」与「更改位置」两个按钮。详见[保存位置与媒体库](/album/storage)。

### 启动音效

一个总开关加六个内置音效的单选。详见[摄像头小窗与启动音效](/record/extras#启动音效)。

### 外部启动

高级版权益说明，以及可复制的 Activity 名称与 Shell 命令。详见[外部启动](/settings/external)。

## 工具

从上到下：

1. **触摸可视化** —— 总开关、四种美化效果、标记大小、标记颜色，以及「添加到控制中心」。详见[触摸可视化](/record/touch)。
2. **运行库** —— 只在 FFmpeg 运行库尚未就绪时出现，四态文案见[运行库](/tools/runtime)。
3. **视频工具** —— 八个 FFmpeg 任务。详见[视频工具箱](/tools/)。

<div class="sr-note">
<strong>运行库未就绪或已有任务在跑时，八个工具都是灰的。</strong>同一时间只允许一个转换任务。
</div>

## 相册

按录制时间列出视频，支持列表与网格两种排布、五种排序基准、多选批量操作。详见[相册](/album/)。

## 悬浮工具栏

主页「控制与安全」里的「启用侧边栏」默认开启。开启后页面右侧有一条竖向悬浮工具栏（圆角 18dp），四个按钮从上到下：

| 按钮 | 说明 |
| --- | --- |
| 悬浮球开关 | 提示文字「启动悬浮球」/「关闭悬浮球」 |
| 触摸可视化 | 提示文字「开启触摸可视化」/「关闭触摸可视化」 |
| 录制 | 提示文字随状态变化：开始录制 / 启动中 / 停止录制 / 继续录制 / 正在保存 |
| 拖动柄 | 提示文字「移动工具栏」，拖动可上下移动位置 |

工具栏位置会记住（默认在屏幕高度的 -88dp 处），并限制在屏幕范围内。录制中录制按钮会变成醒目的红色。

## 悬浮球

与悬浮工具栏相互独立：悬浮球是系统级悬浮窗，可以跨应用使用。点一下开始录制，录制中再点打开控制菜单（暂停 / 继续 / 标注 / 结束 / 收起），长按关闭，拖到下方关闭区域松手也能关闭。详见[悬浮球与工具栏](/record/floating)。
