# 使用指南

五分钟就能录出第一段视频：装好应用 → 在主页挑参数 → 点开始录制 → 在通知栏或悬浮球停止。

## 这个应用能做什么

<ul class="sr-badges">
  <li>系统录屏</li>
  <li>Shizuku 采集（完整版）</li>
  <li>Root 采集（完整版）</li>
  <li>系统声音 + 麦克风混音</li>
  <li>分辨率 / 帧率 / 码率自定义</li>
  <li>H.264 / H.265</li>
  <li>区域录制</li>
  <li>悬浮球控制</li>
  <li>屏幕标注</li>
  <li>前置摄像头小窗</li>
  <li>启动音效</li>
  <li>视频工具箱</li>
  <li>相册管理</li>
</ul>

## 五个步骤

1. **安装并启动**：Android 10（API 29）及以上。首次进入会展示《隐私政策》，同意后进入主页。
2. **挑参数**：主页顶部是「参数预览」，下面是「录制方式」与「画面设置」。不熟悉就保持默认。
3. **开始录制**：点「开始录制」，按提示授予录音权限、确认系统录屏授权（完整版用 Shizuku / Root 时不需要这一步）。
4. **录制中**：通知栏常驻通知可以停止；开了悬浮球就能跨应用开始、暂停、停止。
5. **停止并保存**：停止后应用会合并音视频再写入相册，请等待保存完成的提示。

<div class="sr-note">
<strong>参数在录制期间固定。</strong>中途改分辨率、帧率、声音开关不会立刻生效，需要停止后重新开始——这样输出文件始终是一套一致的参数。
</div>
