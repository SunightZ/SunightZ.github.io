# 声音与增益

录音分两路，各自独立开关、各自有增益，混音后编码为 AAC 写进视频。

## 两路音源

| 音源 | 说明 | 需要 |
| --- | --- | --- |
| 系统声音 | 录制手机内部正在播放的声音（游戏、视频、音乐） | 系统录屏模式：Android 10+ 的播放捕获；Shizuku 模式：Android 13+ |
| 麦克风 | 录制环境声音、解说 | `RECORD_AUDIO` 权限；Shizuku 模式仅麦克风需 Android 11+ |

两路可以只开一个，也可以同时开。

## 增益

- 两路各自 0～200%，**不会修改手机本身的播放音量**。
- 两路相加后限幅，增益过高会削波失真。

<div class="sr-note">
<strong>回声提示：</strong>用扬声器播放声音、同时开麦克风录音，会产生回声与重复音。建议戴耳机录，或者只开一路。
</div>

## 编码参数

| 参数 | 可选值 |
| --- | --- |
| 采样率 | 16 / 22.05 / 24 / 32 / 44.1 / 48 kHz |
| 码率 | 32 ～ 320 kbps |
| 声道 | 单声道 / 双声道 |

## 系统声音的两个实现

- **系统录屏模式**：用 `AudioPlaybackCaptureConfiguration` 捕获本机播放的声音。
- **Shizuku 模式（完整版）**：在 shell 进程里通过 AudioPolicy / LOOP_BACK_RENDER 捕获，**保留本机播放**；停止或失败时会释放 AudioRecord 并注销策略，不会回退到「录到声音但手机变静音」的直采路径。

## 录不到声音时

1. 确认对应开关是开着的，并已授予录音权限（系统设置 → 应用 → 权限）。
2. 有些应用在自身策略里禁止被捕获（受保护音频），这类内容系统不允许录，属于系统限制。
3. Shizuku 模式下确认系统版本满足要求（系统声音 Android 13+，仅麦克风 Android 11+），不满足时应用会明确报错。
4. 检查增益是否被调到 0。
