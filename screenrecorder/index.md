## 两个版本

同一套录制与处理能力，拆成两个工程：**完整版**保留 Root / Shizuku 录制与触摸可视化，**精简版**只保留系统录屏链路，包体与权限都更收敛。

<div class="sr-scroll">

| | <span class="sr-tag full">完整版</span> | <span class="sr-tag lite">精简版</span> |
| --- | --- | --- |
| 系统录屏 | 支持 | 支持 |
| Shizuku 录制（免系统弹窗） | 支持 | — |
| Root 录制（更稳、掉帧更少） | 支持 | — |
| 显示触摸位置 / 触摸可视化 | 支持 | — |
| 声音、区域录制、悬浮球、屏幕标注、视频工具箱、相册 | 支持 | 支持 |
| 面向 | 游戏录制、需要高帧率与低占用 | 日常录屏、只要系统授权 |

## 获取与支持

- **精简版**：随仓库发布，直接安装即可，免费。
- **完整版**：通过开发者公布的社群渠道获取，是否收费以该渠道说明为准。

<div class="sr-note">
<strong>没有账号，也没有云端。</strong>录制文件、处理结果与全部设置都留在本机；卸载应用会删除应用内部的设置与临时文件，你自己保存位置里的视频不会被自动删除。
