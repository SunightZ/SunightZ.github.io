# 常见问题

## 录制

**为什么录出来是黑屏？**
受保护内容（部分应用的 DRM 视频、支付页、银行类界面）系统不允许被捕获，这是系统级限制，任何录屏应用都一样，不是本应用的问题。

**音画不同步 / 卡顿怎么办？**
依次试：降低帧率或分辨率 → 降低码率 → 打开动态帧率/动态码率 → 关掉前置摄像头小窗与悬浮球（它们会占用额外合成开销）→ 完整版可改用 Shizuku 或 Root 采集。

**为什么录不到声音？**
先确认声音开关打开、录音权限已授予（[权限说明](./guide/permissions.md)）。其次确认内容没有被应用自身策略禁止捕获。Shizuku / Root 模式还要满足系统版本：系统声音 Android 13+，仅麦克风 Android 11+。检查增益是否被调到 0。

**录制中途能改参数吗？**
不能。分辨率、帧率、码率、声音开关都在开始录制时固定，改参数需要停止后重新开始——这样输出文件始终是一套一致的参数。

**关键帧间隔在哪设置？**
界面上没有这个选项。默认 2 秒，允许范围 1～10 秒，只能通过设置文件修改。默认值适用于绝大多数场景。

**忘记停止录制了？**
通知栏有常驻通知可以停止；开了悬浮球或悬浮工具栏也能随时停止。都不可用时回到应用内点停止。

**为什么每次开始都要确认一次录屏授权？**
这是 Android 系统录屏（MediaProjection）的机制：授权只对本次会话有效。完整版用 Shizuku 采集可以免掉这个弹窗，代价是需要先安装并启动 Shizuku。

**录出来的文件比预想的小 / 帧数不对？**
帧率是目标/上限，静态画面不保证持续生成这么多帧。录一段不动的画面，文件里可能只有很少的帧，这是正常的。

## 权限

**拒绝了权限，为什么不再弹窗了？**
这是有意设计：明确拒绝过的权限不再重复询问，应用会直接按说明里的降级方式继续（例如拒绝录音就无声录制），并提示一次结果。想重新开启，到「系统设置 → 应用 → 小白录制 → 权限」打开即可，返回后自动恢复。

**悬浮球不出现？**
悬浮球需要悬浮窗权限。到系统设置里允许「显示在其他应用上层」。

**悬浮球会被录进画面吗？**
Shizuku / Root 模式下不会——悬浮球与它的菜单被画在标记为「跳过截屏」的独立图层上。系统录屏模式下会，它本质是一个普通悬浮窗。

**相册看不到我的录制？**
如果自定义了保存位置，那个目录未必被系统媒体库索引——文件确实在，用文件管理器能看到。默认的 `Movies/ScreenRecorder` 会被正常索引。其他可能见[保存位置与媒体库](./album/storage.md#为什么相册看不到我的录制)。

**区域录制为什么直接取消了？**
区域录制没有降级路径：没有悬浮窗权限就没有选区，应用不知道该录哪块画面，所以只能取消本次启动。这与摄像头小窗不同（后者可以关掉小窗继续录）。

## 保存与文件

**停止后提示保存失败？**
保存需要先合并音视频再写入文件。请等「保存完成」。强制结束进程或断电不能保证 MP4 完整；保存失败时临时文件保留在应用私有目录，重新打开应用有机会自动补登记。

**文件在哪儿？**
默认 `Movies/ScreenRecorder`，可在应用内「保存位置」查看或更改，也可以直接从相册、文件管理器取走。提取音频的结果在 `Music/ScreenRecorder`，标注截图在 `Pictures/ScreenRecorder`。

**录了很久的文件能剪辑吗？**
本应用不做时间轴剪辑，但提供旋转镜像、压缩、音量调整、格式转换、提取音频、倒放、超分等常用处理，见[视频工具箱](./tools/index.md)。

**删除的视频能恢复吗？**
不能。相册的删除是直接删除，没有回收站或暂存区。

## 视频工具

**第一次用视频工具为什么在下载？**
FFmpeg 运行库不在安装包里，首次使用时才下载（约 8 MB）。下载后会按内置 SHA-256 逐个校验。不使用视频工具就不会发生这次下载。

**为什么转换后文件反而更大？**
目标格式或码率设置比源更高。换更高的压缩档位或降低分辨率，见[视频压缩](./tools/compress.md)。

**超分能救糊视频吗？**
不能。它只是放大与插值，模糊的细节不会回来。

**倒放被拒绝了？**
倒放需要把画面读进内存再反向输出，所以高分辨率或长视频会被拒绝。先用[视频压缩](./tools/compress.md)降低分辨率再倒放。

**抖音工具为什么输出时长变成两倍？**
它把时间戳整体放大 2 倍，平台按 30 FPS 解码后正好还原成 60 FPS。时长翻倍是正常现象，见[抖音投稿帧数优化](./tools/douyin.md)。

## 版本与高级版

**完整版和精简版怎么选？**
只想把屏幕录下来 → 精简版；要 120 FPS 游戏录制、不想每次确认系统弹窗、需要显示触摸位置 → 完整版。详见[版本对比](./versions.md)。

**哪些功能要高级版？**
Root / Shizuku 采集、屏幕标注、触摸可视化、外部 Activity 静默启动。**系统录屏完全免费且无时长限制**。详见[高级版权益](./premium/index.md)。

**试用怎么算？**
Root / Shizuku 每次 1 分钟，触摸可视化每次开启 1 分钟，都需要联网验证。屏幕标注与外部启动没有试用。详见[试用与限制](./premium/trial.md)。

## 联网与隐私

**应用会联网吗？**
完整版有三处：FFmpeg 运行库下载、高级版激活与心跳、版本检查。精简版只有运行库下载。详见[数据与隐私](./settings/privacy.md)。

**应用收集我的信息吗？**
录制内容、处理结果与配置都留在本机，不上传。完整版的激活链路会发送设备指纹、卡密与机型信息——具体清单与传输方式见[数据与隐私](./settings/privacy.md)。

**崩溃日志会上传吗？**
不会。崩溃报告写在本机，只有你主动点「分享」时才离开设备。

## 兼容性

**我的设备支持多少帧率/分辨率？**
由硬件编码器决定，不是应用写死的上限。参数超出设备能力时应用会在开始前明确报错；首次进入时也会按设备能力把默认值收敛到受支持的最高一档。详见[设备编码器能力](./record/capabilities.md)。

**Shizuku 模式报错？**
Shizuku 的 shell / 隐藏 API 路径依赖系统实现，部分 ROM 需要特殊处理。失败时应用会明确提示，可以取消该选项改用系统录屏模式。

**Android 版本要求？**
Android 10（API 29）及以上。Shizuku 的系统声音需 Android 13+，仅麦克风需 Android 11+（Android 11 上麦克风采集需要解锁后启动）。

**支持 32 位设备吗？**
不支持。构建只包含 arm64-v8a——音视频处理与相册的流读取都建立在 FFmpegKit 上，而它只发布 64 位 ABI。装 32 位版本会得到一个媒体功能无法加载库的应用。
