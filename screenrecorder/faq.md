# 常见问题

## 录制

**为什么录出来是黑屏？**
受保护内容（部分应用的 DRM 视频、支付页、银行类界面）系统不允许被捕获，这是系统级限制，任何录屏应用都一样，不是本应用的问题。

**音画不同步 / 卡顿怎么办？**
依次试：降低帧率或分辨率 → 降低码率 → 打开动态帧率/动态码率 → 关掉前置摄像头小窗与悬浮球（它们会占用额外合成开销）→ 完整版可改用 Shizuku 或 Root 采集。

**为什么录不到声音？**
先确认声音开关打开、录音权限已授予（[权限说明](./guide/permissions.md)）。其次确认内容没有被应用自身策略禁止捕获。Shizuku 模式还要满足系统版本：系统声音 Android 13+，仅麦克风 Android 11+。检查增益是否被调到 0。

**录制中途能改参数吗？**
不能。分辨率、帧率、码率、声音开关都在开始录制时固定，改参数需要停止后重新开始——这样输出文件始终是一套一致的参数。

**忘记停止录制了？**
通知栏有常驻通知可以停止；开了悬浮球也能随时停止。两者都不可用时回到应用内点停止。

**为什么每次开始都要确认一次录屏授权？**
这是 Android 系统录屏（MediaProjection）的机制：授权只对本次会话有效。完整版用 Shizuku 采集可以免掉这个弹窗，代价是需要先安装并启动 Shizuku。

## 权限

**拒绝了权限，为什么不再弹窗了？**
这是有意设计：明确拒绝过的权限不再重复询问，应用会直接按说明里的降级方式继续（例如拒绝录音就无声录制），并提示一次结果。想重新开启，到「系统设置 → 应用 → 小白录制 → 权限」打开即可，返回后自动恢复。

**悬浮球不出现？**
悬浮球需要悬浮窗权限。到系统设置里允许「显示在其他应用上层」。注意悬浮球本身会被录进画面。

**相册看不到我的录制？**
如果自定义了保存位置，那个目录未必被系统媒体库索引——文件确实在，用文件管理器能看到。默认的 `Movies/ScreenRecorder` 会被正常索引。

## 保存与文件

**停止后提示保存失败？**
保存需要先合并音视频再写入文件。请等「保存完成」。强制结束进程或断电不能保证 MP4 完整；保存失败时临时文件保留在应用私有目录，重新打开应用有机会自动补登记。

**文件在哪儿？**
默认 `Movies/ScreenRecorder`，可在应用内「保存位置」查看或更改，也可以直接从相册、文件管理器取走。

**录了很久的文件能剪辑吗？**
本应用不做时间轴剪辑，但提供旋转镜像、压缩、音量调整、格式转换、提取音频等常用处理，见[视频工具箱](./tools.md)。

## 版本与权限

**完整版和精简版怎么选？**
只想把屏幕录下来 → 精简版；要 120 FPS 游戏录制、不想每次确认系统弹窗、需要显示触摸位置 → 完整版。详见[版本对比](./versions.md)。

**应用会联网吗？**
只有一处：首次使用视频工具箱时从开发者公布的公开地址下载 FFmpeg 运行库，并按内置 SHA-256 逐个文件校验。没有激活校验、没有版本检查、没有统计上报。

**应用收集我的信息吗？**
不收集。没有账号体系、没有广告、没有用户画像、不接入任何统计/推送/社交/支付/风控服务，录制内容与配置都留在本机。详见[隐私政策](./privacy.md)。

## 兼容性

**我的设备支持多少帧率/分辨率？**
由硬件编码器决定，不是应用写死的上限。参数超出设备能力时应用会在开始前明确报错；首次进入时也会按设备能力把默认值收敛到受支持的最高一档。

**Shizuku 模式报错？**
Shizuku 的 shell / 隐藏 API 路径依赖系统实现，部分 ROM 需要特殊处理。失败时应用会明确提示，可以取消该选项改用系统录屏模式。

**Android 版本要求？**
Android 10（API 29）及以上。Shizuku 的系统声音需 Android 13+，仅麦克风需 Android 11+（Android 11 上麦克风采集需要解锁后启动）。
