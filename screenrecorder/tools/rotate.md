# 旋转与镜像

修正录屏方向，支持 90°/180° 与镜像。

## 五种变换

对话框里的「变换方式」下拉：

| 选项 | 效果 |
| --- | --- |
| 顺时针 90° | 向右转 90° |
| 逆时针 90° | 向左转 90° |
| 旋转 180° | 上下颠倒 |
| 水平镜像 | 左右翻转 |
| 垂直镜像 | 上下翻转 |

对话框上有一行说明：

> 旋转会改变画面尺寸，因此需要重新编码。

## 编码参数

| 项目 | 值 |
| --- | --- |
| 视频编码器 | H.264（硬件优先，软件回退） |
| 码率 | 按源视频短边取画质档位（与[格式转换](/tools/convert#码率怎么定)同一套） |
| 音频 | 恒定重编为 AAC 192 kbps |
| 输出格式 | MP4（带快速起播标记） |

旋转 90° 或 270° 时，输出的宽高会互换。

## 什么时候用

| 场景 | 选 |
| --- | --- |
| 横屏录的内容在竖屏播放器里侧着 | 顺时针或逆时针 90° |
| 视频整个上下颠倒 | 旋转 180° |
| 前置摄像头自拍镜像反了 | 水平镜像 |
| 倒装拍摄 | 旋转 180° |

<div class="sr-note">
<strong>录屏本身方向就是对的。</strong>本应用在录制时已经用 OpenGL 层把画面旋到正确方向，所以录出来的文件一般不需要这一步。这个工具主要处理外部素材，或者处理「录制方向」被手动设成横屏/竖屏而结果不符预期的情况。
</div>
