# 音量调整

手动增益或响度标准化。改的是**已有文件**，与录制时的混音增益是两件事。

## 两种处理方式

对话框里的「处理方式」下拉：

### 响度标准化（默认）

> 按 EBU R128 标准化，适合人声与解说。

按 EBU R128 标准把整段音频的响度归一到 **-16 LUFS**，真峰值上限 **-1.5 dBTP**，响度范围 11 LU。这是流媒体平台常用的响度目标。

好处是不用自己猜增益值：录制音量忽大忽小的素材，标准化后听感会一致。

### 手动增益

滑块范围 **-20 ～ +20 dB**，步进 1 dB，实时显示形如 `+6 dB` 或 `-3 dB`。

- 想放大声音：正值
- 想压低声音：负值

## 编码参数

| 项目 | 值 |
| --- | --- |
| 视频 | **直接复制，不重新编码** |
| 音频编码器 | 输出为 WebM 时用 libopus，否则用 AAC |
| 音频码率 | 192 kbps |
| 输出格式 | 沿用源扩展名（MP4 / MOV / MKV / WebM），其他源回落到 MP4 |

对话框上有一行说明：

> 视频画面直接复制，只重新编码音频。

这是这个工具最大的优点：**画面零损失、处理速度极快**，因为只需要解码再编码音轨。

## 什么时候用

| 场景 | 选 |
| --- | --- |
| 录屏解说音量忽大忽小 | 响度标准化 |
| 整体声音太小，听不清 | 手动增益 +6 ～ +12 dB |
| 整体声音太大，爆音 | 手动增益 -3 ～ -10 dB |
| 想统一一批素材的响度 | 响度标准化（逐个处理） |

<div class="sr-note">
<strong>已经失真的声音救不回来。</strong>如果录制时增益调到 200% 导致削波，标准化只会把失真一起放大或缩小。录音时的增益要留余量。
</div>

## 和录制增益的区别

| | 录制时的混音增益 | 音量调整 |
| --- | --- | --- |
| 作用对象 | 正在录制的音频 | 已经存在的文件 |
| 范围 | 0～200% | -20～+20 dB，或响度标准化 |
| 能否补救 | 是源头 | 是后期 |
| 视频画面 | 一起录 | 直接复制，不动 |
