# 音量调整

手动调整音量，或让整段声音的响度统一。改的是**已有视频**，与录制时的音量设置是两件事。

## 两种处理方式

对话框里的「处理方式」下拉：

### 响度标准化（默认）

> 按 EBU R128 标准化，适合人声与解说。

把整段音频的响度统一到一个标准水平。好处是不用自己猜该调多少：录制音量忽大忽小的素材，处理后听感会一致。

### 手动增益

滑块范围 **-20 ～ +20 dB**，步进 1 dB，实时显示形如 `+6 dB` 或 `-3 dB`。

- 想放大声音：正值
- 想压低声音：负值

## 画面不会变

对话框上有一行说明：

> 视频画面直接复制，只重新编码音频。

这是这个工具最大的优点：**画面零损失、处理速度极快**，因为它只处理音轨。

## 什么时候用

| 场景 | 选 |
| --- | --- |
| 录屏解说音量忽大忽小 | 响度标准化 |
| 整体声音太小，听不清 | 手动增益 +6 ～ +12 dB |
| 整体声音太大，爆音 | 手动增益 -3 ～ -10 dB |
| 想统一一批素材的响度 | 响度标准化（逐个处理） |

<div class="sr-note">
<strong>已经失真的声音救不回来。</strong>如果录制时音量调太高导致破音，标准化只会把破音一起放大或缩小。录音时的音量要留余量。
</div>

## 和录制音量的区别

| | 录制时的音量设置 | 音量调整 |
| --- | --- | --- |
| 作用对象 | 正在录制的音频 | 已经存在的视频 |
| 范围 | 0～200% | -20～+20 dB，或响度标准化 |
| 画面 | 一起录 | 直接复制，不动 |
