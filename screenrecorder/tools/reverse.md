# 视频倒放

画面与声音同时倒序，输出 MP4。文件时长不变。

## 使用

1. 点「视频倒放」，选择一个视频。
2. 对话框会显示一段说明：「画面与声音同时倒序输出，文件时长不变。」
3. 点「开始处理」。

处理过程分两阶段，界面上会显示进度：先分段处理，再合并。分辨率越高、视频越长，需要的时间越久。

## 会被拒绝的情况

倒放需要把画面读进内存再反向输出，所以对视频的尺寸和长度有要求。以下情况应用会直接拒绝并说明原因，而不是冒险处理失败：

| 情况 | 提示 |
| --- | --- |
| 读不到时长 | 无法读取视频时长，不能安全地倒放 |
| 分辨率过高 | 视频分辨率过高或无法读取，倒放可能耗尽内存 |
| 尺寸异常 | 无法安全处理此视频尺寸，请先缩小分辨率 |
| 读不到帧率 | 无法读取有效帧率，不能安全地倒放 |
| 视频过长 | 视频过长，倒放需要过多临时分段 |

遇到这些提示时，先用[视频压缩](/tools/compress)把分辨率降下来，再倒放。

## 什么时候用

- 把一段动作倒过来看
- 做循环播放的素材
- 检查某个操作的反向过程
