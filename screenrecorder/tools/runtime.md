# 运行库

视频工具箱需要一套额外的运行库。应用**不把它放进安装包**，而是在你首次使用视频工具时下载。

<div class="sr-note">
<strong>不使用视频工具箱，就不会发生这次下载。</strong>应用其余功能都不需要联网。
</div>

## 下载与校验

| 项目 | 说明 |
| --- | --- |
| 大小 | 约 8 MB |
| 时机 | 首次进入工具页时 |
| 校验 | 下载后逐个文件校验，不通过的不会被使用 |

下载地址有两个，主地址不通时会自动改用备用地址，所以偶尔的网络波动不会让工具用不了。

下载完成后工具页的「运行库」区块会显示「FFmpeg 运行库已就绪」，八个工具随之可用。

## 界面上的四种状态

| 状态 | 标题 | 说明 |
| --- | --- | --- |
| 未下载 | 下载 FFmpeg 运行库 | 视频工具需要额外下载约 8 MB 的运行库 |
| 下载中 | 正在下载 FFmpeg 运行库 | 显示下载进度百分比 |
| 就绪 | FFmpeg 运行库已就绪 | 视频工具可以使用 |
| 失败 | 重新下载 FFmpeg 运行库 | 显示错误原因，点击重试 |

## 下载失败怎么办

按顺序排查：

1. **检查网络**：下载需要联网，切到可用的 Wi-Fi 或移动数据后点重试。
2. **检查应用网络权限**：确认系统设置里没有禁止本应用联网。
3. **再试一次**：主地址不通时会自动切换备用地址，重试通常能成功。
4. **仍有问题**：错误提示会说明具体原因（例如「下载服务器返回 HTTP …」），可以据此反馈。

<div class="sr-note">
<strong>运行库没就绪时，八个视频工具都是灰的</strong>，但录屏、相册、设置等其余功能不受影响。
</div>
