# 视频格式转换

转为 GIF 动图，或 MP4 / MKV / MOV / WebM 等格式。

## 目标格式

对话框里的「目标格式」下拉：

| 选项 | 适合什么 | 说明 |
| --- | --- | --- |
| MP4 · H.264 | 发给别人、要最大兼容性 | 兼容性最好 |
| MP4 · H.265 | 存档、想省空间 | 同画质体积更小，老设备播放兼容性略差 |
| MKV · H.264 | 需要多音轨、多字幕 | 多轨封装容器 |
| MOV · H.264 | 要导入剪辑软件 | 剪辑软件友好 |
| WebM · VP9 | 要嵌到网页里 | 浏览器与网页友好 |
| GIF 动图 | 做动图表情、贴到聊天里 | 两遍调色板，可设宽度与帧率 |

## 音质会不会变差

**不会，如果目标格式装得下原音轨的话。**

- MP4 / MOV 可以直接沿用 AAC、MP3 等常见音轨，**不重新编码**。
- MKV 还能再沿用 Opus、Vorbis、FLAC。
- 装不进去时才会重新编码一次，并尽量保持原有音质水平。
- **GIF 不含声音**。

## 画质怎么定

没有单独的码率选项——应用会按**源视频的清晰度**自动选一个合适的档位，所以转换后的文件大小与原文件大致相当。

想主动控制大小请用[视频压缩](/tools/compress)。

## GIF 的两个选项

转 GIF 时会多出两个滑块：

| 选项 | 范围 | 说明 |
| --- | --- | --- |
| 宽度 | 240 px ～ 源宽度 | 越大越清晰、文件越大 |
| 帧率 | 6 ～ 50 FPS | 越大越流畅、文件越大 |

<div class="sr-note">
<strong>GIF 天生很大。</strong>它没有帧间压缩，所以一段几秒的屏幕录制转成 GIF 可能有几十 MB。想要小文件，把宽度调到 480 以下、帧率降到 12 左右。
</div>

## 什么时候用

| 你的目标 | 选 |
| --- | --- |
| 发给别人、要最大兼容性 | MP4 · H.264 |
| 存档、想省空间、播放端支持 | MP4 · H.265 |
| 要导入剪辑软件 | MOV · H.264 |
| 要嵌到网页里 | WebM · VP9 |
| 要做动图表情 | GIF 动图 |
