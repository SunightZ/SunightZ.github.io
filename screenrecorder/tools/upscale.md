# 视频超分

放大画面并重新生成视频。

<div class="sr-note">
<strong>先说清楚：放大不会凭空增加细节。</strong>它只是把画面变大并平滑填补，原本模糊的细节不会回来。实际用途是让低分辨率录制在大屏上不那么糊，或者统一不同素材的分辨率。
</div>

## 放大倍数

滑块范围 **1.0× ～ 上限**，步进 0.1×。上限与源视频的尺寸有关：

| 源分辨率 | 大约能放大到 |
| --- | --- |
| 1080p | 4.0× |
| 4K | 2.0× |
| 较小素材 | 8.0× |

对话框上会实时显示换算结果：

> 输出分辨率 `1920 × 1080` → `3840 × 2160`

以及一段说明：

> 上限 `N.N`× 由 8K 长边换算得出。画面本身不会凭空多出细节；倍数越高处理负担越大，输出尺寸还需设备编码器支持。

## 什么时候值得用

| 场景 | 建议 |
| --- | --- |
| 低分辨率录屏要在电视上放 | 2× 通常够 |
| 老素材要和新素材混剪，分辨率不一致 | 放大到统一尺寸 |
| 想从 1080p 得到"4K 文件" | 可以，但不会有 4K 细节——只是文件更大 |
| 想救糊掉的视频 | **不行**，换别的手段 |

**1.0× 是一个特殊值**：只重新生成一次，不改变画面大小。想换格式或调画质又不想动尺寸时可以用它。

## 输出尺寸要设备支持

放大后的分辨率还需要你的手机支持。例如 1080p 素材放大 4× 得到 4320×7680，很多设备不接受这个尺寸，会提示失败。遇到时降低倍数再试。
