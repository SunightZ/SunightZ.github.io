# 提取音频

从视频中取出音轨，存成 MP3 / M4A / WAV / FLAC / OGG。

## 输出格式

对话框里的「输出格式」下拉：

| 选项 | 适合什么 | 说明 |
| --- | --- | --- |
| MP3 音频 | 发给别人、要通用 | 最通用的音频格式 |
| M4A · AAC | 手机录制的视频，想**无损**取出 | 同画质更省空间 |
| WAV 无损 | 要拿去二次编辑 | 未压缩，体积很大 |
| FLAC 无损 | 要无损但想省点空间 | 无损压缩 |
| OGG · Vorbis | 要开源格式 | 开源音频格式 |

## 什么时候是无损的

这是这个工具最值得知道的一点：**当原音轨能直接装进目标格式时，应用直接取出音轨，不做任何重新编码**。

所以：

- 手机录制的视频、绝大多数在线视频，音轨都是 AAC → **选 M4A 就是无损提取**，音质与原始完全一致，而且很快。
- MP3 源的视频 → 选 MP3 是无损的。
- FLAC 源的视频 → 选 FLAC 是无损的。

反过来，AAC 源提取成 MP3 就必须重新编码一次（有损转有损，会再损失一次）；提取成 WAV 或 FLAC 虽然格式无损，但源头已经是有损的，音质不会变好。

<div class="sr-note">
<strong>想无损就选 M4A。</strong>这是最常见也最实用的选择。
</div>

## 提取出来的文件在哪

与录制相同的保存位置，音频类默认在 `Music/ScreenRecorder`。输出文件只有声音，没有画面。

## 什么时候用

| 你的目标 | 选 |
| --- | --- |
| 从录屏里取出解说或音乐，要通用 | MP3 音频 |
| 源是 AAC（大多数情况），要**无损** | M4A · AAC |
| 要拿去二次编辑、不介意体积 | WAV 无损 |
| 要无损但想省点空间 | FLAC 无损 |
| 要开源格式 | OGG · Vorbis |
