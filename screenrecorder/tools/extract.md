# 提取音频

从视频中提取 MP3 / M4A / WAV / FLAC / OGG。

## 输出格式

对话框里的「输出格式」下拉：

| 选项 | 说明 | 容器 | 编码器 | 可无损复制 |
| --- | --- | --- | --- | --- |
| MP3 音频 | 最通用的音频格式 | MP3 | `libmp3lame` | MP3 源 |
| M4A · AAC | 同画质更省空间 | M4A | AAC | AAC 源 |
| WAV 无损 | 未压缩，体积很大 | WAV | PCM 16-bit | 各种 PCM |
| FLAC 无损 | 无损压缩 | FLAC | FLAC | FLAC 源 |
| OGG · Vorbis | 开源音频格式 | OGG | `libvorbis` | Opus / Vorbis 源 |

## 无损提取

这是这个工具最值得说的一点：**当源音轨的编码能直接装进目标容器时，应用直接复制音轨，不做任何重新编码**。

所以：

- AAC 源的视频 → **M4A**：无损提取，音质与原始完全一致
- MP3 源的视频 → **MP3**：无损提取
- FLAC 源的视频 → **FLAC**：无损提取

反过来，AAC 源提取成 MP3 就必须重编码（有损转有损，会再损失一次）；提取成 WAV 或 FLAC 虽然容器无损，但源头已经是有损的，音质不会变好。

### 码率怎么定

需要重编码时：

- **无损格式（WAV / FLAC）不设码率**——它们本来就不按码率工作。
- 有损格式按**源音轨的码率**重编，夹在 64～320 kbps 之间；探测不到源码率时用 192 kbps。

视频流会被完整丢弃，输出文件只有音频。

## 什么时候用

| 你的目标 | 选 |
| --- | --- |
| 从录屏里取出解说或音乐，要通用 | MP3 音频 |
| 源是 AAC（大多数手机录制与视频），要**无损** | M4A · AAC |
| 要拿去二次编辑、不介意体积 | WAV 无损 |
| 要无损但想省点空间 | FLAC 无损 |
| 要开源格式 | OGG · Vorbis |

<div class="sr-note">
<strong>想无损就选 M4A。</strong>手机录制的视频、绝大多数在线视频的音轨都是 AAC，提取成 M4A 走的是直接复制，一秒完成且零损失；提取成 MP3 则会重新编码一遍。
</div>
