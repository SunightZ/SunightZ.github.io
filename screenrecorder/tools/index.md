# 视频工具箱

录完不用换 App。工具箱把常用的视频处理做成点击即用，**同一时间只跑一个任务**，结果保存到与录制相同的保存位置，**原文件不动**。

## 八个工具

按工具页上的实际顺序：

| 工具 | 做什么 |
| --- | --- |
| [视频格式转换](/tools/convert) | 转成 MP4 / MKV / MOV / WebM / GIF |
| [提取音频](/tools/extract) | 从视频里取出音轨，存成 MP3 / M4A / WAV / FLAC / OGG |
| [视频压缩](/tools/compress) | 按目标体积或码率重新压缩，适合分享 |
| [视频超分](/tools/upscale) | 2× / 3× / 4× 放大画面 |
| [旋转与镜像](/tools/rotate) | 修正录屏方向，支持 90°/180° 与镜像 |
| [视频倒放](/tools/reverse) | 画面与声音同时倒序 |
| [音量调整](/tools/volume) | 手动增益或响度标准化 |
| [抖音投稿帧数优化](/tools/douyin) | 让 60 FPS 视频投稿后不被压到 30 FPS |

## 怎么用

1. 点工具页上的某一项（第一次用会先让你[下载运行库](/tools/runtime)）。
2. 通过系统文件选择器选一个视频。**选完立刻读取文件信息**——时长、分辨率、帧率、音轨编码都会显示在对话框上。
3. 在对话框里调参数（每个工具的选项见各自页面）。底部固定显示一行 `输出：<格式>`。
4. 点「开始处理」。
5. 处理中会显示进度百分比与已处理时长，随时可以点「取消转换」。

<div class="sr-note">
<strong>同一时间只跑一个任务。</strong>有任务在跑时，其他工具都是灰的。任务在前台运行，退出界面可以，但别强制结束进程。
</div>

## 处理中的显示

进度对话框标题「正在转换」，副标题是「目标格式 · 输出文件名」，进度文本显示百分比，并会追加速度倍率与已处理时长。点「取消转换」后进入「正在取消」状态，正文「正在停止转码，请稍候…」。

## 结果

处理完成后会弹出结果窗口：

| 标题 | 什么时候 |
| --- | --- |
| 转换完成 | 成功 |
| 保存失败 | 处理成功但写文件失败 |
| 转换失败 | 处理本身失败 |

按钮有「打开」（用系统播放器打开结果）、「分享」（仅有可用地址时）与「确定」。打开失败提示「没有可打开该格式的应用」。

结果默认保存在与录制相同的保存位置。如果那里写不进去，应用会自动改用系统媒体库或应用自己的目录，并在提示里说明实际位置。

## 常见失败提示

| 提示 | 含义 |
| --- | --- |
| 请先在工具页面下载 FFmpeg 运行库 | 运行库没装好 |
| 无法读取所选文件 | 选中的文件打不开 |
| 临时空间不足：读取该文件约需 N MB，当前可用 M MB | 缓存空间不够 |
| FFmpeg 报告成功但没有写出任何数据，请换一种输出格式或换一个源文件 | 处理失败，换个格式或换源文件 |
| 转码已完成，但保存失败：… | 见上面的保存说明 |
| 转换已取消 | 你点了取消 |
