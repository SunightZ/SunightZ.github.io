# 视频压缩

按目标体积或码率重新编码，适合分享。

## 三种设置

| 控件 | 选项 |
| --- | --- |
| 压缩方式 | 按目标体积 / 按码率 |
| 分辨率上限 | 原画 / 2160 / 1440 / 1080 / 720 / 480 |

### 按目标体积

滑块范围 **5～200 MB**，步进 5 MB。选好后应用会显示换算结果，形如：

> 按时长与音频开销换算，约 8 Mbps

换算方式是：从目标体积里先扣掉音频占用的部分（按 128 kbps 估算），剩下的分给视频，再除以时长。算出来的码率会被限制在 1～100 Mbps 之间。

音频开销有下限保护，所以极短的视频不会被算出一个不可用的码率。

### 按码率

直接选视频码率：**2 / 4 / 6 / 8 / 12 / 20 / 30 Mbps**，默认 8 Mbps。

### 分辨率上限

选一个上限后，短边超过它的视频会被等比缩小；**已经比上限小的视频不会被放大**——压缩工具不会做上采样。

## 编码参数

| 项目 | 值 |
| --- | --- |
| 视频编码器 | H.264（硬件优先，软件回退） |
| 音频 | 恒定重编码为 AAC 128 kbps |
| 输出格式 | MP4（带快速起播标记） |

<div class="sr-note">
<strong>音频恒定重编为 128 kbps。</strong>这一点和其他工具不同——压缩的目标就是小，所以不做音轨复制。
</div>

## 怎么选参数

| 你的情况 | 建议 |
| --- | --- |
| 平台限制上传体积（如 100 MB） | 按目标体积，填略小于限制的值 |
| 想控制清晰度 | 按码率：1080p 用 8～12 Mbps，720p 用 4～6 Mbps |
| 只是想发个朋友圈 | 按目标体积 20 MB + 分辨率上限 1080 |
| 文件不大但想再小一点 | 只调分辨率上限，码率按源来 |

<div class="sr-note">
<strong>压缩后反而变大？</strong>说明你设的码率或分辨率比源还高。看一眼对话框上显示的源信息，把参数调到源以下。
</div>
