# 保存位置与相册

## 默认位置

| 类型 | 位置 |
| --- | --- |
| 视频 | `Movies/ScreenRecorder` |
| 音频（提取音频的结果） | `Music/ScreenRecorder` |
| 图片（标注截图） | `Pictures/ScreenRecorder` |

这些目录会被系统相册正常收录，所以录完就能在系统相册、文件管理器里看到。

## 自定义位置

在主页「保存位置」里点「更改位置」，通过系统文件选择器挑一个文件夹。授权会**持久保存**，重启应用后依然有效。

点「使用默认」回到 `Movies/ScreenRecorder`。

<div class="sr-note">
<strong>自定义文件夹是否显示在系统相册里取决于系统索引。</strong>有些第三方的文件管理器目录不会被相册扫描——文件确实在那里，用文件管理器能看到，但相册应用里可能找不到。
</div>

### 云盘之类的位置

如果你选的文件夹背后是云盘，录制会先暂存在应用内部，等录制结束或下次打开应用时再搬进你选的目录。文件不会丢，只是要等一会儿。

## 视频工具箱的输出

工具箱的结果与录制使用**同一个保存位置**，原文件不动。如果那里写不进去，应用会自动改用系统相册目录或应用自己的目录，并在提示里说明实际位置。

## 为什么相册看不到我的录制

按可能性排序：

1. **自定义了保存位置** —— 那个目录可能没被系统相册收录。文件确实在，用文件管理器能看到。默认的 `Movies/ScreenRecorder` 会被正常收录。
2. **还没保存完** —— 刚停止录制时，保存需要一点时间，等「保存完成」提示。
3. **权限被拒** —— 相册页会显示「已拒绝访问视频权限」，给一个「去系统设置」按钮。
4. **登记失败** —— 重新打开应用会触发自动补登记，并提示「补登记 N 段录制到相册」。

## 录制中断了怎么找回

如果录制因为应用被划掉、手机重启等原因中断，重新打开应用时会自动处理并提示：

| 提示 | 含义 |
| --- | --- |
| 移入 N 段暂存的录制 | 把没搬完的录制放进你选的文件夹 |
| 补登记 N 段录制到相册 | 把相册里看不到的录制重新登记 |
