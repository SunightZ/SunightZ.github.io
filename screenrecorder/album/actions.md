# 播放、分享与信息

## 播放

在非选择模式下点任意一项，用**系统默认播放器**打开（`ACTION_VIEW` + `video/*`），并授予临时读取权限。所以播放体验取决于你装了哪个播放器。

没有可打开的应用时提示：

> 没有可打开视频的应用

## 分享

**单个视频**：在选择模式下选中它，点「更多操作」→「分享」。

**多个视频**：选中多个，同样从「更多操作」里分享。

分享走系统分享面板（`ACTION_SEND_MULTIPLE`），可以一次发送多个文件，会带一个「分享视频」的标题。没有可用应用时提示：

> 没有可用的分享应用

## 视频信息

**只选中一个视频**时，「更多操作」旁边会多出一个「查看视频信息」入口（点击后会清空选择）。信息窗口按轨道分组：

### 文件

| 字段 | 说明 |
| --- | --- |
| 文件名 | 完整文件名 |
| 位置 | 所在路径 |
| 大小 | 文件体积 |
| 时长 | 播放时长 |
| 格式 | 容器格式（有值时显示） |

### 视频轨道

标题、编码、分辨率（形如 `1920 x 1080`）、帧率、码率。

- 帧率会去掉多余的尾随零，形如 `59.94 fps`
- 码率自动选单位：Gbps / Mbps / kbps / bps
- 读不到的项显示 `—`

### 音频轨道 #N

每条音轨一组：标题、编码、采样率、采样格式、码率、声道、语言。

编码名会做美化，Dolby 系列会显示成 `Dolby Atmos`、`Dolby Digital Plus`、`Dolby Digital`、`Dolby TrueHD Atmos`、`Dolby TrueHD`、`Dolby AC-4` 这样的可读名称。

### 字幕轨道 #N

每条字幕一组：标题、编码、语言。

语言代码会转成语言名显示。

<div class="sr-note">
<strong>轨道信息需要 FFmpeg 运行库。</strong>没有装运行库时，窗口仍会打开，但只显示系统媒体库能提供的那部分字段（文件名、大小、时长、分辨率等），编码与码率这类详细信息会缺失。
</div>
