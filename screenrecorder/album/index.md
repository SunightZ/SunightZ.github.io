# 相册

应用内置相册页，列出本机视频，支持列表与网格两种排布、多选批量操作。

## 显示哪些视频

相册的数据来源取决于你有没有自定义保存位置：

| 保存位置 | 相册显示什么 |
| --- | --- |
| 默认（`Movies/ScreenRecorder`） | 系统相册里这个目录下的视频 |
| 自定义文件夹 | **只显示该文件夹内的视频** |

<div class="sr-note">
<strong>为什么自定义后只显示那一个文件夹？</strong>否则无关文件夹的视频会一起漏进这个页面，反而看不出"我的录制在哪"。
</div>

## 每一项显示什么

- **缩略图**：取不到时显示一个播放图标占位
- **标题**：默认显示去掉扩展名的文件名；没有扩展名时显示「未命名视频」
- **元信息行**：分辨率（形如 `1080p`）与文件大小
- **时长角标**：右下角半透明黑底白字，形如 `12:34`

文件大小按 KB / MB / GB 显示。

## 选择模式

- **长按**任意一项进入选择模式
- 选择模式下**单击**切换该项的选中状态
- 顶栏标题变成「已选 `N`/`M`」
- 左侧图标变成「取消选择」，右侧出现「全选」/「取消全选」与「更多操作」
- **只选中一项**时会额外出现「查看视频信息」入口
- 按返回键清空选择

选中项在缩略图右上角显示一个圆形勾选标记。
