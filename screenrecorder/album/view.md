# 排序、布局与显示字段

点相册页右上角的「快捷设置」打开一个对话框，标题「快捷设置」，三组设置。改动是草稿式的——点「完成」才生效，点「取消」全部丢弃。

## 视频布局

两个选项：「列表」与「网格」。

- **列表**：一行一项，缩略图占左侧，宽度取屏幕宽度的 35%（上限 150dp），缩略图比例 16:10。
- **网格**：自适应列数，每格最小宽度 160dp 乘以缩略图缩放系数。

只有选了「网格」才会出现缩略图大小设置：

| 控件 | 说明 |
| --- | --- |
| 缩略图大小 | 范围 75% ～ 150%，步进 5% |
| 缩小 / 放大 / 重置 | 三个按钮，重置回到 100% |

## 排序

两个 Tab 行：第一行选排序基准，第二行选方向。

| 排序基准 | 升序标签 | 降序标签 |
| --- | --- | --- |
| 标题 | A-Z | Z-A |
| 时长 | 最短 | 最长 |
| 路径 | A-Z | Z-A |
| 大小 | 最小 | 最大 |
| 日期（默认） | 最旧 | 最新 |

默认是**日期降序**，也就是最新的排在前面。

标题与路径排序用的是**自然序**：`video2` 会排在 `video10` 前面，而不是按字符逐个比较得出 `video10` 在前。标题排序时会忽略扩展名。

切换排序时页面会保持滚动位置——应用会记住你当前看到的那一项，重排后滚回它。

## 显示字段

一组可多选的标签，控制列表项上显示哪些信息：

| 字段 | 显示效果 |
| --- | --- |
| 时长 | 右下角的时长角标 |
| 扩展名 | 标题是否带扩展名 |
| 分辨率 | 元信息行里的 `1080p` |
| 大小 | 元信息行里的文件体积 |
| 缩略图 | 是否显示缩略图 |

默认开启时长、分辨率、大小与缩略图。

<div class="sr-note">
<strong>有两个字段会被自动剔除。</strong>设置里若残留「播放进度」或「路径」，读写时都会被过滤掉——当前版本不显示这两项。
</div>

## 这些设置存在哪

相册视图偏好保存在本机，与录制配置分开：

- 布局（列表 / 网格）
- 缩略图缩放
- 排序基准与方向
- 显示字段集合

## 下拉刷新

列表支持下拉刷新，文案依次是「下拉刷新」「松开刷新」「正在刷新…」「刷新完成」。

录制完成后进入相册会自动刷新，不需要手动下拉。
