# 解锁与激活

## 入口

主页右上角菜单里的「解锁高级版」——**只在未激活时出现**。

另外，当你选择 Root / Shizuku 模式却没有激活时，会自动弹出解锁提示。

## 解锁对话框

标题「解锁高级版」，摘要「开发不易，感谢支持ヾ(≧▽≦*)o」。

内容：

- 一个输入框，标签「请输入卡密」
- 两个链接：「查看全部高级版权益」与「没有卡密？前往商城购买」
- 按钮「取消」与「激活」（校验中变成「验证中…」）

卡密为空时点「激活」会提示「请输入卡密」。

「查看全部高级版权益」打开权益页；「没有卡密？前往商城购买」打开商城页面；没有可用的浏览器时提示「没有可打开商城的浏览器」。

## 模式拦截对话框

当你选了 Root 或 Shizuku 模式但还没激活时，会看到另一个对话框：

- 标题「该模式需解锁高级版」
- 内容：三张功能对比图
- 按钮「继续体验」与「前往购买」
- 提示文字「未激活：Root / Shizuku 可体验 1 分钟」

从控制中心磁贴触发时，这个对话框的标题是「解锁专业录制能力」。

## 激活流程

1. 点「激活」。
2. 应用联网验证卡密。**这一步需要网络**。
3. 验证通过后，卡密会绑定到你的设备，激活完成。
4. 对话框关闭，Root / Shizuku 录制与触摸可视化的时长限制解除。

<div class="sr-note">
<strong>建议在可信网络下激活。</strong>不要在公共 Wi-Fi 上输入卡密。详见<a href="/settings/privacy">数据与隐私</a>。
</div>

## 设备绑定

卡密会绑定到**激活时使用的那台设备**。

这是为了防止一个卡密被多台设备同时使用。如果你换手机，需要用原来的卡密在新设备上重新激活；如果提示卡密已被绑定，请联系购买渠道。

## 激活之后

- Root / Shizuku 录制不再有 1 分钟限制
- 触摸可视化不再有 1 分钟限制
- 屏幕标注可用
- 外部 Activity 静默启动可用

## 没有卡密时

- **先试一下**：Root / Shizuku 与触摸可视化都有 1 分钟试用，见[试用与限制](/premium/trial)。
- **购买**：从解锁对话框里的「没有卡密？前往商城购买」进入。
