# 高级版权益

高级版解锁四项专业能力：**Root / Shizuku 高性能录制、屏幕标注、触摸可视化、外部 Activity 静默启动**。

<div class="sr-note">
<strong>系统录制（MediaProjection）完全免费，且没有时长限制。</strong>1 分钟的限制只作用于 Root / Shizuku 采集。
</div>

## 四项权益

### 1. Root / Shizuku 专业录制

在游戏录制、高画质和高帧率场景中，通过系统级显示与音频通道直接建立采集链路，减少应用层转发、权限代理和跨进程调度带来的等待。

采集、音频混流与视频编码可以更稳定地并行执行，降低主线程和游戏渲染线程受到的干扰，改善帧时间一致性，减少高负载时的丢帧、卡顿和音画不同步。

**适合场景**：游戏高帧率录制、长时间教程录制、需要更低后台干扰的专业采集。

激活后**解除 1 分钟体验限制**，可持续录制。详见[实测数据](/premium/benchmark)。

### 2. 屏幕标注

录制过程中可直接在屏幕上进行重点标记，让讲解、演示更直观。支持四种工具：

| 工具 | 用途 |
| --- | --- |
| 自由画笔 | 快速圈出重点区域或书写提示 |
| 矩形框 | 突出显示界面、按钮和关键区域 |
| 圆形 | 强调目标位置或操作结果 |
| 箭头 | 指向具体控件、方向或变化位置 |

同时支持预设颜色、画笔粗细调节、撤销、清空画布和**标注截图**。截图会保存完整屏幕内容以及当前标注，适合制作教程配图或留存操作记录。

**未激活时完全不可用**——没有试用，打开会提示「屏幕标注需要激活高级版」。详见[屏幕标注](/record/annotation)。

### 3. 触摸可视化

把每一次触摸实时画在屏幕上，用于讲解操作、录制教学视频，或在演示时让观众看清手指落点。

需要在 Root 或 Shizuku 权限下运行，因为普通应用无法读取触摸设备节点。**无需开始录制即可单独使用**，也可以从控制中心磁贴一键开关。

提供四种触摸效果：

| 效果 | 说明 |
| --- | --- |
| 光晕圆点 | 径向柔光，无硬边，默认效果 |
| 涟漪扩散 | 扩散圆环加柔和核心 |
| 拖尾彗星 | 沿手指真实轨迹渐隐收尖，适合滑动演示 |
| 轨道光环 | 双环反向旋转 |

标记颜色默认跟随当前主题，也可以指定预设色或自行取色；标记大小可在 4–24 dp 之间调节。

**未激活时每次开启可体验 1 分钟**，与 Root / Shizuku 专业录制的限制一致。详见[触摸可视化](/record/touch)。

### 4. 外部 Activity 静默启动

激活后可通过外部命令从 GestureEVO 等第三方自动化或手势应用静默调用录制行为。入口读取应用中已保存的录制配置，并跟随控制中心磁贴的行为设置，启动录制或悬浮菜单。

**未激活时调用该入口，会显示提示并立即结束**，不会启动录制或悬浮球。详见[外部启动](/settings/external)。
