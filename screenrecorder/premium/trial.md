# 试用与限制

未激活高级版时，有两项功能可以试用，一项完全不可用。

| 功能 | 未激活时的限制 |
| --- | --- |
| Root / Shizuku 录制 | 每次 1 分钟 |
| 触摸可视化 | 每次开启 1 分钟 |
| 屏幕标注 | **完全不可用**，没有试用 |
| 外部 Activity 静默启动 | **完全不可用** |
| 系统录屏 | 无限制 |

## Root / Shizuku 的 1 分钟

选择 Root 或 Shizuku 模式但未激活时，会弹「该模式需解锁高级版」，提示「未激活：Root / Shizuku 可体验 1 分钟」，两个按钮：

- **继续体验** —— 按 1 分钟限制开始录制
- **前往购买** —— 打开商城

1 分钟到点后会提示：

> 免费录制已达到 1 分钟，请激活高级版

试用由**录制进程自己计时**，所以即使应用被划掉或被杀，试用也不会超时继续跑。

### 试用需要联网

Root / Shizuku 的试用走一条**独立的验证链路**，必须联网验证通过才能开始：

| 结果 | 行为 |
| --- | --- |
| 验证通过 | 提示「试用卡密验证通过，最多可录制 1 分钟」，60 秒后自动结束 |
| 网络或卡密失败 | 提示「网络异常，体验已结束」或「卡密验证失败：…，录制已停止」并立即结束 |

<div class="sr-note">
<strong>试用必须先联网验证通过。</strong>离线状态下无法开始试用，这是设计如此——离线设备不该被当成盗版，但试用本身需要一次成功验证。
</div>

### 试用期间的提示

| 情况 | 提示 |
| --- | --- |
| 验证通过 | 试用卡密验证通过，最多可录制 1 分钟 |
| 时间到 | 体验结束 |
| 网络问题 | 网络异常，体验已结束 |
| 卡密被拒 | 卡密验证失败：…，录制已停止 |

## 触摸可视化的 1 分钟

未激活时，工具页的触摸可视化区块底部会显示一行主色小字：

> 未激活：每次开启可体验 1 分钟

1 分钟到点后提示：

> 触摸可视化免费体验已达到 1 分钟，请激活高级版

并自动关闭。

这个计时由**服务自身强制**，所以从控制中心磁贴启动也绕不过。持有永久授权则不计时。

## 为什么试用需要联网

试用的验证与永久激活走的是同一套授权体系，只是用了另一套应用参数与一张随程序分发的试用卡密。这样做的结果是：

- 试用不能靠改本地时间或断网来延长
- 试用与正式激活互不干扰（两套参数各自独立，会话状态不会互相污染）

## 试用之后

试用结束时录制会**正常收尾并保存**——MP4 会完整写出，不会留下一个损坏的文件。所以试用的那 1 分钟内容是拿得回来的。
