# 实测数据

Root / Shizuku 的画面更稳，**负载越高、帧率越高，差距越明显**。

<div class="sr-note">
<strong>数值为同一台设备上的对比结果，会随设备与负载变化。</strong>测试条件是同一台设备、播同一段内容、使用完全相同参数（原始分辨率 @ 屏幕最高刷新率）。
</div>

## 数值

| 指标 | 系统录制 | Shizuku | Root |
| --- | --- | --- | --- |
| 每帧 CPU 耗时 | 8.89 ms | 6.40 ms | 6.20 ms |
| 超预算帧 | 1.87% | 1.27% | 1.25% |
| 掉帧 | 1.70% | 1.45% | 1.24% |

## 怎么读这组数

**每帧 CPU 耗时** —— 录制一帧要花多少 CPU 时间。120 FPS 的每帧预算是 8.3 ms，系统录制平均已经超了，Shizuku / Root 还有余量。这就是"能不能稳住 120 FPS"的分界。

**超预算帧** —— 每一百帧里，处理超时的帧有多少。从 1.87% 降到 1.27%，少了三分之一。

**掉帧** —— 观众能感知到的卡顿。从 1.70% 降到 1.24%。

Shizuku 与 Root 差距不大，Root 略优。

<div class="sr-note">
<strong>这组数据来自一次发布前的实测，不是每台设备的实时测量。</strong>你的设备上差距可能更大也可能更小——低负载场景（静态画面、低帧率）下三者几乎没有区别，差距主要体现在高帧率游戏录制。
</div>

## 适合什么场景

| 场景 | 建议 |
| --- | --- |
| 录静态画面、看文档 | 系统录屏就够，三种方式没差别 |
| 录 60 FPS 游戏 | Shizuku 或 Root，画面更稳 |
| 录 120 FPS 游戏 | Root 最稳 |
| 长时间录制 | Root（录制过程不依赖应用） |
| 不想每次点系统弹窗 | Shizuku 或 Root |
