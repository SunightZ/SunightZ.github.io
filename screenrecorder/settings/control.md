# 控制与安全

主页「控制与安全」区块里的设置，以及控制中心磁贴的行为。

## 添加到控制中心

摘要「添加小白录制磁贴，快速控制录制」。

- **Android 13 及以上**：直接弹出系统确认框。
- **更低版本**：系统没有这个接口，应用会提示你手动添加——「请下拉控制中心，点击编辑，将"小白录制"磁贴拖入已添加区域」。

添加结果的各种提示：

| 结果 | 提示 |
| --- | --- |
| 已添加 | 已添加到控制中心 |
| 已存在 | 控制中心已添加"小白录制"磁贴 |
| 未添加 | 未添加磁贴，可在控制中心的编辑页面手动添加"小白录制" |
| 有请求在进行 | 已有磁贴添加请求，请先完成系统弹窗中的操作 |
| 系统不支持 | 此系统不支持申请添加磁贴，请在控制中心的编辑页面手动添加"小白录制" |

## 磁贴点击行为

磁贴副标题跟随状态：未录制时「开始录制」，录制中「录制任务进行中」，停止时短暂显示「正在保存」。

**录制中点击** → 立即停止，并提示「停止失败：…」（如果失败）。这个分支不需要打开任何页面。

**未录制时点击** → 分两种情况，由下面的开关决定。

## 磁贴启动悬浮菜单

摘要「若关闭则直接启动录制」。**默认关闭。**

| 设置 | 点击磁贴的效果 |
| --- | --- |
| 关闭（默认） | 直接开始录制 |
| 开启 | 唤起悬浮球菜单 |

无论哪种，磁贴点击都会先打开一个透明的检查页（因为签名校验与 Shizuku 探测需要时间，而磁贴必须立刻交出页面）。检查期间显示「正在准备启动录制…」与「正在校验授权…」。

检查通过后：

- 有区域录制配置 → 进入选区流程
- 否则 → 进入录屏授权流程

检查失败时的提示：

| 情况 | 提示 |
| --- | --- |
| Shizuku 未启动或未授权 | 请先启动 Shizuku 并授权，授权后重试磁贴 |
| 没有保存过录制配置 | 请先回到主页设置录制参数 |
| 需要解锁高级版 | 弹「解锁专业录制能力」对话框 |
| 启动失败 | 无法启动录制：… |

<div class="sr-note">
<strong>磁贴需要先配置一次。</strong>首次使用请先在主页配置并启动一次录制，磁贴会沿用上次的参数。
</div>

## 启用流体云通知

**仅在 Android 16 及以上显示。**摘要「可能需要在通知中心中进行额外设置」。

开启后录制状态会以实时通知（部分机型称"实时通知"或"流体云"）的形式展示，通知动作变成「暂停」「标注」「结束」。

首次开启会先弹说明：

> 流体云通知需要开启本应用的实时通知权限：点击"继续授权"后，在系统的通知设置中允许小白录制发送实时通知（部分机型称为"实时通知"或"流体云"），返回后开关即可生效。

## 息屏后暂停录制

摘要「息屏后录制暂停，亮屏后自动恢复。若息屏超过6分钟，将自动结束录制。」**默认关闭。**

开启后锁屏会暂停录制而不是继续消耗电量；超过 6 分钟则自动结束并保存。

## 启用侧边栏

摘要「在页面右侧显示悬浮工具栏（悬浮球开关、录制按钮、拖动柄）。」**默认开启。**

详见[悬浮球与工具栏](/record/floating#悬浮工具栏)。

## 悬浮窗设置

摘要「大小、不透明度、圆角与颜色」，打开一个底部弹窗：

| 项目 | 范围 | 默认 |
| --- | --- | --- |
| 悬浮窗大小 | 48 ～ 64 dp | 52 dp |
| 悬浮窗不透明度 | 20 ～ 100% | 88% |
| 悬浮窗圆角 | 0 ～ 24 dp | 10 dp |
| 悬浮窗颜色 | 取色板 | `#33373D` |

三个滑杆实时预览，点「保存」写入，点「取消」回滚。详见[主题与外观](/settings/theme#悬浮窗外观)。

## 录制通知

录制期间有一条常驻通知，按状态变化：

| 状态 | 标题 | 动作 |
| --- | --- | --- |
| 启动中 | 启动中 / 录制准备中 | — |
| 录制中 | 正在录制 | 暂停 / 标注 / 停止并保存 |
| 已暂停 | 录制已暂停 | 继续 / 停止并保存 |
| 保存中 | 正在保存 | — |
| 完成 | 录制完毕 | 点击查看 |

开启麦克风降噪时标题会追加「· 降噪」。

「标注」动作是[屏幕标注](/record/annotation)的入口之一（高级版功能）。
