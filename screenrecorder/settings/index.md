# 设置总览

应用没有独立的"设置页"——所有设置都分布在主页的各个区块里，改动即时保存。

## 设置分布在哪

| 区块 | 位置 | 内容 |
| --- | --- | --- |
| 录制方式 | 主页 | Shizuku / Root 开关、显示触摸位置 |
| 画面设置 | 主页 | 区域录制、前置摄像头、方向、编码、画质、分辨率、帧率、码率、动态调整 |
| 声音设置 | 主页 | 系统声音、麦克风、降噪 |
| 高级设置 | 主页（需展开「精细调整」） | 码率模式、采样率、音频码率、声道、两路音量 |
| [控制与安全](/settings/control) | 主页 | 磁贴、流体云、息屏暂停、侧边栏、悬浮窗外观 |
| 保存位置 | 主页 | 输出目录 |
| 启动音效 | 主页 | 开关与六种音效 |
| [外部启动](/settings/external) | 主页 | 给第三方手势应用的入口 |
| 触摸可视化 | 工具页 | 开关、效果、大小、颜色、磁贴 |
| 运行库 | 工具页 | 视频工具的运行库状态 |
| [主题与外观](/settings/theme) | 主页菜单 →「更改主题」 | 浅色 / 深色与主题色 |
| 相册视图 | 相册页 →「快捷设置」 | 布局、排序、显示字段 |

## 设置存在哪

全部保存在本机，**不会上传**。卸载应用会一并删除这些设置；你自己保存位置里的视频不会被自动删除。
