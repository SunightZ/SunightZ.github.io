# 设置总览

应用没有独立的"设置页"——所有设置都分布在主页的各个区块里，改动即时保存。

## 设置分布在哪

| 区块 | 位置 | 内容 |
| --- | --- | --- |
| 录制方式 | 主页 | Shizuku / Root 开关、显示触摸位置 |
| 画面设置 | 主页 | 区域录制、前置摄像头、方向、编码、画质、分辨率、帧率、码率、动态调整 |
| 声音设置 | 主页 | 系统声音、麦克风、降噪 |
| 高级设置 | 主页（需展开「精细调整」） | 码率模式、采样率、音频码率、声道、两路增益 |
| [控制与安全](/settings/control) | 主页 | 磁贴、流体云、息屏暂停、侧边栏、悬浮窗外观 |
| 保存位置 | 主页 | 输出目录 |
| 启动音效 | 主页 | 开关与六种音效 |
| [外部启动](/settings/external) | 主页 | 第三方自动化入口 |
| 触摸可视化 | 工具页 | 开关、效果、大小、颜色、磁贴 |
| 运行库 | 工具页 | FFmpeg 下载状态 |
| [主题与外观](/settings/theme) | 主页菜单 →「更改主题」 | 色彩模式、主题色、调色板、色彩规范 |
| 相册视图 | 相册页 →「快捷设置」 | 布局、排序、显示字段 |

## 设置存在哪里

全部保存在应用私有的本机存储里，分为几组：

| 组 | 内容 |
| --- | --- |
| 录制参数 | 数值参数（同时存整数与字符串两种形式）、所有开关、保存位置、录制方式、录制区域 |
| 录制快照 | 完整配置的序列化副本，**同步落盘**——控制中心磁贴和外部启动入口可能在设置页写入后立刻被调用，异步写盘会让它们读到旧值 |
| 相册视图 | 布局、缩略图缩放、排序、显示字段 |
| 界面状态 | 引导是否已读、悬浮工具栏位置 |
| 触摸可视化 | 开关、效果、大小、颜色、是否用 Root |
| 主题 | 色彩模式、主题色、调色板风格、色彩规范 |
| 高级版凭据 | 激活凭据 |

这些数据都**不会上传**。卸载应用会一并删除；你自己保存位置里的视频不会被自动删除。

## 录制配置的快照机制

录制参数除了一份完整快照，还有一层考虑：**录制区域**的确认带一个版本号。

从悬浮球、磁贴或区域选区改过范围后，版本号会更新；主页在恢复时比对版本号，发现变化才覆盖自己的显示。这样跨入口改的范围能正确同步，而不会出现"主页显示的是旧范围、实际录的是新范围"。
