# 数据与隐私

这一页说明应用会处理哪些信息、什么时候联网、什么会离开你的设备。

<div class="sr-note">
<strong>本页记录的是完整版（含 Shizuku / Root 录制与高级版激活）的情况。</strong>精简版没有这些功能，因此没有激活相关的联网行为。站内<a href="/privacy">隐私政策</a>是面向精简版的文本，差异见本页末尾。
</div>

## 留在本机的内容

以下内容**不会**离开你的设备：

| 内容 | 位置 |
| --- | --- |
| 录制的视频与音频 | 你选择的保存位置 |
| 标注截图 | `Pictures/ScreenRecorder` |
| 相册里的视频 | 只读取用于显示与播放，不上传 |
| 麦克风与摄像头内容 | 只写入录制文件 |
| 触摸位置 | 只用于当次绘制，不保存 |
| 崩溃报告 | 应用内部，只有你主动点「分享」才会离开设备 |
| 全部设置与配置 | 应用内部 |

### 崩溃报告

应用出错时会记录一份错误信息，并存一条通知「小白录制发生异常」。点开可以看到详情，页面上有「复制」与「分享」两个按钮。

**只有你主动点「分享」时，报告才会离开设备。**关闭查看页会删除它。

### 机身倾斜角度

底部导航栏的毛玻璃效果会随机身倾斜轻微变化，因此界面需要读取手机的倾斜角度：

- 只在界面显示期间读取，界面离开时立即停止
- 数值只用于当次绘制，**不保存、不写入文件、不上传**
- 不与任何信息组合用于识别你

## 什么时候联网

### 1. 下载视频工具的运行库

首次使用视频工具箱时，会下载约 8 MB 的运行库。这次下载不包含你的任何文件或个人信息。

**不使用视频工具箱，就不会发生这次下载。**

### 2. 高级版激活

完整版的 Shizuku / Root 录制需要激活。激活时会与授权服务器通信，完成卡密验证与设备绑定，之后定期保持连接。

这条链路会离开设备的信息：

| 信息 | 说明 |
| --- | --- |
| 设备标识 | 用于把卡密绑定到你的设备，防止一个卡密被多台设备使用 |
| 卡密 | 你输入的激活码 |
| 应用版本号 | 用于版本检查 |
| 机型与系统版本 | 用于兼容性判断 |
| IP 地址 | 联网时必然暴露 |

**不会**上传：录制的视频与音频、屏幕内容、相册视频、麦克风与摄像头内容、触摸位置、崩溃日志。

<div class="sr-note">
<strong>激活链路的安全强度低于应用的其他联网行为。</strong>应用下载运行库时走的是加密连接，而激活校验这条链路的传输保护较弱。建议在可信网络（如自己的家庭 Wi-Fi）下完成激活，不要在公共 Wi-Fi 上输入卡密。
</div>

### 3. 版本检查

激活时会顺带检查是否有新版本。有新版本时会在应用内提示。

更新方式是**打开浏览器**：应用把下载链接交给系统浏览器，由你决定是否下载安装。应用**不自己下载安装包、不申请安装权限、不做静默安装**。

录制过程中如果检测到新版本，会显示一张提示卡：标题「检测到新版本」，正文「建议您进入小白录制app进行更新」。这张提示**不会被录进画面**。

## 完整性校验

应用会校验自己的安装包是否被修改过（例如被二次打包）。如果发现异常，应用会**直接退出**——没有弹窗、没有上报。

对用户来说表现为：应用突然退出，没有任何解释。遇到这种情况通常意味着安装包被改动过，建议从官方渠道重新安装。

## 权限与处理时机

所有权限都在你使用对应功能时才申请，不会在同意隐私政策的瞬间集中申请。逐项说明见[权限说明](/guide/permissions)。

## 第三方组件

应用使用了音视频处理、界面与加密等若干开源组件。它们都在本机运行，**不会把数据传输给各自的作者**。具体清单见[隐私政策](/privacy)第六条。

应用**没有**接入任何第三方统计、广告、推送、社交、支付或崩溃上报服务。

## 与站内隐私政策的差异

站内[隐私政策](/privacy)是面向**精简版**的文本，其中这两句不适用于完整版：

> 没有激活校验、没有版本检查、没有统计上报。

> 唯一的联网行为是第五条的运行库下载，该下载不包含你的任何文件。

完整版（Shizuku / Root 录制 + 高级版激活）额外有激活校验与版本检查。如果你要更新隐私政策，需要按本页内容补充这几项。
