# 主题与外观

主页菜单里的「更改主题」打开一个对话框，标题「更换主题」，摘要「色彩模式、主题色与调色板」，四个下拉选项。改动是草稿式的——点「使用」才生效，点「取消」全部丢弃。

## 色彩模式

六种：

| 选项 | 说明 |
| --- | --- |
| 跟随系统（默认） | 系统是深色就深色 |
| 浅色 | 固定浅色 |
| 深色 | 固定深色 |
| 莫奈跟随系统 | 用取色生成调色板，明暗跟随系统 |
| 莫奈浅色 | 用取色生成调色板，固定浅色 |
| 莫奈深色 | 用取色生成调色板，固定深色 |

<div class="sr-note">
<strong>只有三种「莫奈」模式会用到下面两项。</strong>普通的浅色/深色忽略主题色，所以选了它们时，「主题色」以及「调色板风格」「色彩规范」都会置灰——置灰而不是隐藏，这样对话框的形状不会随选择变化。
</div>

## 主题色

八种，仅在莫奈模式下可用：

| 选项 | 色值 |
| --- | --- |
| 默认 | 由系统壁纸决定 |
| 蓝 | `#3482FF` |
| 绿 | `#36D167` |
| 紫 | `#7C4DFF` |
| 黄 | `#FFB21D` |
| 橙 | `#FF5722` |
| 粉 | `#E91E63` |
| 青 | `#00BCD4` |

选「默认」时不指定种子色，由系统壁纸提供调色板。

## 调色板风格

九种，只在「莫奈模式 + 选了非默认主题色」时可用：

`TonalSpot`（默认）、`Neutral`、`Vibrant`、`Expressive`、`Rainbow`、`FruitSalad`、`Monochrome`、`Fidelity`、`Content`

这一项直接显示英文枚举名——它们是调色算法的名称，没有通用的中文译法。

## 色彩规范

两种，可用条件同上：

| 选项 | 说明 |
| --- | --- |
| Spec2021（默认） | 较早的色彩规范 |
| Spec2025 | 较新的色彩规范 |

## 深色模式下标题会变

浅色主题时主页标题是「小白录制」，深色主题时变成「小黑录制」。这是同一处代码按当前主题取的字符串，不是两个应用。

## 其他外观元素

### 液态玻璃导航栏

底部导航栏（宽屏下是左侧导航栏）用了毛玻璃与折射效果，高光会随**机身倾斜**轻微变化。

<div class="sr-note">
<strong>这需要读取机身倾斜角度。</strong>界面组件在本机调用系统的旋转矢量传感器，仅在界面显示期间读取，界面离开时立即注销；数值只用于当帧绘制，不保存、不写入文件、不上传。
</div>

在低版本系统上，模糊与着色器效果会自动停用，不会报错。

### 首次引导的彩带

首次引导结束时有一次彩带庆祝动画。它会临时把窗口刷新率提到屏幕支持的最高档，让动画跑在该有的帧率上，动画结束后立即恢复。系统关闭动画时不会播放。

### 悬浮窗外观

主页「控制与安全」→「悬浮窗设置」，四组：

| 项目 | 范围 | 默认值 |
| --- | --- | --- |
| 悬浮窗大小 | 48 ～ 64 dp | 52 dp |
| 悬浮窗不透明度 | 20 ～ 100% | 88% |
| 悬浮窗圆角 | 0 ～ 24 dp | 10 dp |
| 悬浮窗颜色 | 取色板（12 行 × 18 列） | `#33373D` |

三个滑杆都是**实时预览**的——拖动时屏幕上的悬浮球立刻跟着变，点「保存」才写入，点「取消」回滚到原值。
